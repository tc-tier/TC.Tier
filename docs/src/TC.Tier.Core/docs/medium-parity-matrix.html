概念平权矩阵（活文档——medium-protocol-and-parity-design §4 的收口形态）

维护规则（设计 §7.2 准入流程）：任何文件系统要新增建设面概念，先在下面矩阵填自己那格，然后回答其余 三格——实现 ✓ / 映射 ◐（注明语义）/ 豁免 ✗†（层错位/物理不存在，附证明）。三样都拿不出来就不合入。 与 io.md §7 能力位矩阵（运行行为）互补：本表管词汇面（消费者必须能表达什么），那张管运行面。 三态：✓ 已实现 / ◐ 映射（形态不同） / ✗† 豁免（附证明）。

运行面概念衔接

持久化（数据比进程活得久）：本地/虚拟 = 原地 Flush；网络 = Flush(PUT)；内存 = 无原地持久化层， 持久化点 = 运行时导出（RootSpaceImage——概念全额成立，机制豁免）。其余运行行为见 io.md §7 能力位矩阵 与 §6.2 差异声明表。
