    运行面概念衔接

    持久化（数据比进程活得久）：本地/虚拟 = 原地 Flush；网络 = Flush(PUT)；内存 = 无原地持久化层， 持久化点 = 运行时导出（RootSpaceImage——概念全额成立，机制豁免）。其余运行行为见 io.md §7 能力位矩阵 与 §6.2 差异声明表。
