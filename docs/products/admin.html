Tier 管理面（healthz/readyz/状态导出/admin 协议）——二期-D1

探针语义

探针 API 语义
healthz node.GetStateSnapshot().Healthy 循环存活（无 LoopException）且已启动——停摆/故障 = false
readyz node.GetStateSnapshot().Ready 已知 leader（含自身在位）——分区/选举中 = false（不返回过期承诺）

状态导出

node.GetStateSnapshot() 返回 RaftStateSnapshot： Role / Term / LeaderId / CommitIndex / AppliedIndex / LastLogIndex / SnapshotIndex / IsVoter / Healthy / Ready / Members（leader 视角复制进度：各成员 matchIndex + lag）。

远程查询（admin 协议·0x70 产品面）

// 服务端挂载（每节点一次——0x70 注册区产品自管号）
var admin = new TierRaftAdmin(transport, () => node.GetStateSnapshot());

// 远程查询（任意节点/客户端——经传输请求回调）
var state  = await TierRaftAdmin.QueryStateAsync(transport, targetId, ct);   // 全量状态 + 成员复制进度
var health = await TierRaftAdmin.QueryHealthAsync(transport, targetId, ct);  // 轻量 healthz/readyz

状态供给回调返回 null = 节点未就绪——探针应答 Healthy=false（fail-closed）。
