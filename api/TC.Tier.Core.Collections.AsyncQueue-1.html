    Class AsyncQueue<T>

    异步生产-消费队列。基于 ConcurrentQueue<T> + 池化等待节点， 常规路径（队列非空时出队、入队唤醒）零堆分配。 出队发现队列为空时，租用独立完成源挂入等待链；入队时唤醒链首一个等待者。

    注意：本类不是通用 Channel，不支持单消费者背压 / 完成（Complete）等高级语义。 适合内核 IO 响应队列等"持续运行、永不关闭"的场景。
