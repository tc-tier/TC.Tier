版本分配器（tierkv-design.md §3.2，D1=session-version）：全局单调分配——会话创建自分配器取版本 （会话区间 = 本版本至下一分配之间的代际标签）；分配器高水位经 Ring opaque meta 持久化 （随 2PC Prepare 原子落盘），恢复期续接（新分配版本恒大于历史——版本单调不回退）。

★ 检查点粒度版本（版本图=分配器高水位+环水位+索引几何，W5 入帧）——记录级版本标签 不存在（append-only Ring 记录无版本字段；快照/版本读按检查点版本定位水位重放，F3/W5）。

★ opaque 布局（24B）：[0..8) 高水位 little-endian + [8..12) 魔数 "TKV1"——代际守卫， 代际演进换魔数值 + [12..16) 过期回收扫描水位 SegId + [16..24) 扫描水位 Offset （A.2a——ExpirySweep 增量游标，恢复从水印续扫不重复全扫；SegId<0 = 未持久化态）。 编码经 [BinaryLayout] 生成 Codec（KvVersionOpaqueCodec）——零手写字节序； 高水位读取兼容旧 12B 块（短块零扩展解读——魔数在 [8..12) 不变）。
