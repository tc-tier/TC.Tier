    Interface ILifecycle<THints>

    生命周期持有者统一接口。全部 LifecycleBase<THints> 派生类实现此接口—— 数据结构基类（Log/Ring/Index/Metadata/Blob）与 IO 引擎（StorageEngine）。 泛型参数 THints 为各持有者自己的恢复 hints struct。

    ★ 接口面只保留观测/等待契约（IsReady / RecoveryState / 事件 / WaitForReady* / CancelRecovery）； LifecycleBase<THints>.Initialize 启动入口不在接口面——启动由各持有者自己的装配面提供 （引擎 = StorageEngineBuilder.Start/StartAsync 一步到位；结构 = 组合器/生成代码内部调用）， 不允许外部经接口直接调 Initialize（详见 src/TC.Tier.Core/docs/lifecycle.md）。

    ★ 与 IRecovery<TRecoveryHints> 正交：ILifecycle 是生命周期持有者对外观测契约， IRecovery 是恢复算法契约（可注入替换），LifecycleBase.Initialize 内部委托 IRecovery.Recover。

    Methods

    CancelRecovery()

    取消恢复（向内部后台恢复发取消信号，不保证立即停止）。

    后台恢复在下一个 checkpoint 检查取消令牌并抛 OperationCanceledException。

    ★ 契约：WaitForReady() / WaitForReadyAsync(CancellationToken) / WaitForReady(int) 在取消恢复时会抛 OperationCanceledException（取消=等待被中断）。

    void CancelRecovery()

    WaitForReady()

    同步等待恢复完成（内部 join 后台恢复 task，阻塞当前调用线程直到 Ready）。

    ★ 与 Initialize 的关系：Initialize 启动后台恢复后立即返回； 调用方若需"启动后立即阻塞等就绪"，在 Initialize 后调本方法。

    ★ 不阻塞其他数据结构，只阻塞调用本方法的线程。

    ★ 若恢复已失败（Failed），本方法重抛恢复异常。

    ⚠️ 禁止在异步上下文调用：UI/ASP.NET 等同步上下文下，同步阻塞后台 Task 会经典死锁。 异步调用方请用 WaitForReadyAsync(CancellationToken)。

    Declaration
    void WaitForReady()
