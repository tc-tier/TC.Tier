池化的单次完成 IValueTaskSource——每次 Rent 一个独立实例， SetResult() / SetException(Exception) 后归还复用。

多 waiter 广播的正确做法：每个 waiter 持有独立的 PooledValueTaskSource 实例 （而非共享一个 core），由发起方在全部完成时逐个 Set。这与 AsyncManualResetEvent 的共享 core 语义互补：本类型面向"一次性、单消费者"的高频 IO 唤醒场景。

双层池化（thread-local Stack<T> 热路径 + ConcurrentStack<T> 全局回退 + 批量搬运）， 常规 Rent/Return 往返零争用、零堆分配。

MarkOrComplete()

★ 完成先于注册的安全完成入口（#PERF-002）：标记"发起方已完成"；若 continuation 已注册则立即 SetResult，否则留待 OnCompleted(Action<object>, object, short, ValueTaskSourceOnCompletedFlags) 转发处兜底完成。

替代裸 SetResult——裸 SetResult 在未注册时触发 BCL 的 CompletionSentinel，后者在 continuation 缺席/core 已 Reset 归还后抛 InvalidOperationException（进程级崩溃）。
