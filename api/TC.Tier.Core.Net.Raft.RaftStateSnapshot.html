统一状态导出快照（二期-D1 NETGAP-005——健康/就绪/管理面的数据面）： Role/LeaderId/Term/CommitIndex/AppliedIndex/日志尾/快照覆盖点/成员与复制进度 + healthz/readyz 语义。

★ readyz 语义：Ready = 本端角色为 Leader 或已知 leader（LeaderId 非空）—— 分区/选举中 = not ready（探针语义：不返回过期承诺）。

★ healthz 语义：Healthy = 循环存活（无 LoopException）且已启动——停摆/故障 = unhealthy。
