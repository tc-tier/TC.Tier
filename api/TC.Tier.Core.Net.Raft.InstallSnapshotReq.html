InstallSnapshot 请求（spec-03 §2）——快照已经注入传输面送达，本 RPC 只做同步点握手： follower 收到后导入（读注入面）+ 重建业务状态 → 应答 N₀ → leader nextIndex = N₀+1 推增量。

★ 握手面协调数据（spec-12 §6.1 SwarmSync × T6 接线）：Swarm = true 时 携带多源块清单（ManifestId/BlockSize/TotalBytes/ Checksums）+ 持有者表（Holders）——follower 据此多源拉取； false = 单源流式（数据面自带一切，协调字段为零值）。
