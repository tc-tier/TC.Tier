PeerController

PeerMechanism

HyParView 挂载件（spec-12 §6 × §1 机制零特权——机制在自身命名空间实现挂载形态， 经 INodeMechanism 端口走与第三方/私有域同一挂载路径；装配四面零机制知识 （TCSG061 机器锁）的兼容形态）。

★ MountAsync：PeerController 构造 + StartAsync（内部口注册 0x02）→ seed 非空时 JoinAsync(seed)（有界等待——JoinWaitTimeout 兜底，seed 不可达 不挂装配）；seed 为空 = 部署种子自身（只启动不 JOIN——发现从种子扩散）。

★ Gossip 广播 opt-in（WithBroadcast(BroadcastOptions?)）：挂载时一并构造 SwarmBroadcast（视图提供者接控制器——一行委托，机制间零握手），随会员机制 同生命周期；Broadcast 挂载后为使用句柄（未开启 = null）。

PhiAccrualDetector

PhiAccrual 统计故障检测器（spec-06 §5 参数化——论文 Hayashibara 等）。

原理：心跳到达间隔采样窗口 → 正态分布拟合（均值/标准差）→ 当前距上次心跳的时间 换算 φ = -log₁₀(1 − Φ((Δt − μ)/σ))——φ 越大 = 越不可能仍存活。

★ 默认 φ=8 ≈ 误判率可忽略（spec-06 §2/§5）；样本不足时 φ=0（不判失败——冷启动宽限）。

ShuffleMsg

SHUFFLE 被动视图定期交换（spec-06 §2——成员搅动收敛）。

SwarmBroadcast

Gossip 广播（spec-06 §6 dissemination 件——最终一致性广播；IBroadcast 实现）。

★ 语义（spec-06 §6 语义要点）：沿活跃视图扇出（fanout ≤ k）、MsgId 去重（同消息全网 至多投递一次）、TTL 逐跳减一（减尽即停——环路面保险）；不保证顺序/不保证送达（P2P 模式定位， 数据报尽力语义）。

★ 组合（机制挂载面）：构造收活跃视图提供者委托——会员关系零类型依赖（PeerMechanism 装配时接 ActiveView）；广播是独立组件，会员管理器不含广播 （spec-06 语义纪律）。

★ 通道：协议域 Gossip（0x05）数据报，Udp bearer 声明 （gossip/成员消息走数据报形态——spec-12 §6 机制面）；出站尽力发送经 TaskSink （同步完成零分配快路径，异常组内观测）。

★ 契约：handler 快进快出（介质读循环内同步回调——spec-12 §7）； MessageReceived 订阅方同契约（重活自排队）。
