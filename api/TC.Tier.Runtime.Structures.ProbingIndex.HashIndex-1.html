    GrowIndex()

    ★ 扩容（容量自适应的活器官——装载超 TC.Tier.Runtime.Structures.ProbingIndex.HashIndex`1.GrowthLoadFactor 由 Insert 触发）：表翻倍。

    ★ 纯函数式构建：新表+新溢出池全新分配（旧代零扰动），收集旧代全部 Occupied entry （主表 slot 0..6 + 每条 overflow 链）→ 经 KeyResolver 读回真 key 重算 hash 按新 mask 落位 → _table 单引用原子发布。并发读者持旧代引用继续一致探测（条目仍真、仅缺发布后新插， stale-but-valid——与 BTree 根晋升缓存全清同级容忍），旧代归 GC——无需 epoch 排水 （无内存回收竞态：溢出指针只在同代内解引用）。

    ★ rehash 逐条 TryGetKey（tag 14 位不足以重建 64 位 hash）——重放/增长期地址序近邻， Ring 冷页缓存（≥数据页数时全热）承接；均摊成本 O(1)/插（翻倍序列总 rehash ≤ 2×条目数）。
