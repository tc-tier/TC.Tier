    Class StreamSnapshot

    StreamSnapshot——GB/TB 大数据流的流式帧实现（原 StreamBlockBlob 的 LifecycleBase 化继任者）。

    帧格式：[Header 14B][Data][Footer 28B（Magic+TotalLength+EntryCount+Crc64）]； 多帧支持（Complete 后 ResetFrame 可再开新帧）。帧写入器 CRC64 增量流式累积（边写边算，不驻内存整块）。

    ★ 生命周期：new + Initialize()（后台恢复）+ WaitForReady()。详见 src/TC.Tier.Core/docs/lifecycle.md。
