Class UnifiedCrc

Namespace
TC.Tier.Core.Primitives
Assembly
TC.Tier.Core.dll

统一 CRC 计算工具——仓库持久/传输格式校验和的唯一出口（unified-binary-layout.md §2 的 FLAG_CRC32 / FLAG_CRC32C / FLAG_CRC64 三算法均由本族（UnifiedCrc + UnifiedCrc64）自研覆盖， 产品代码零 System.IO.Hashing 依赖；结构侧按格式规范选算法）。

CRC32C（Castagnoli 反射多项式 0x82F63B78）：硬件加速。x86 走 Sse42.Crc32（每 cycle 8B）， ARM 走 Crc32.ComputeCrc32C（每 cycle 4B）；无硬件平台回退自建软件表。格式族（示例）： TierVolume 帧/Delta/Journal/Carrier/Superblock、RecordCodec（FLAG_CRC32C）、Ring overflow、Meta、Wire/Swarm、WAL 快照。

CRC32（IEEE 802.3，反射多项式 0xEDB88320，zlib 语义）：软件查表零分配，与 System.IO.Hashing.Crc32 逐位一致（迁移调用点不改动已落盘/在途校验值）。用于格式规范指定 IEEE 的场合： TCA1/TCE1 image 帧与流尾聚合、TransactionLog 提交记录、Compact 标记、NetworkImageTransfer 回执。

CRC64（ECMA-182 多项式；实例型增量经 UnifiedCrc64，见 CreateCrc64()）： 常驻归档抗位衰减（RecordCodec FLAG_CRC64、Snapshot、SortedIndex/ProbingIndex、Mirror FLAG_CRC64 帧等）。

★ 一次性路径零分配零 TLS（CRC64 静态直算；CRC32C 内建指令、CRC32 查表）——均无对象分配。
