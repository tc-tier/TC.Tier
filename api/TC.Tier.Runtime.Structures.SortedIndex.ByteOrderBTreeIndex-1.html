key 字节序 B+树封闭形态（W7 F1 范围/前缀扫描的排序底座）：BTreeIndex 的编译期封闭 + 内置 KeyByteOrderComparer<TKey>——字节字典序（RocksDB/LMDB 同款范围扫描通用序， 前缀 = 字节区间，多字段结构体 key 按字段布局序排布）。

★ 消费面：TierKv 范围索引挂载（EnableRangeIndex）/ 任何需要 key 字节序有序索引的组合。 开放泛型 BTreeIndex（默认数值/结构序）不落消费面，同 BlittableRing 律。
