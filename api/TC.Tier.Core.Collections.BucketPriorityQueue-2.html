离散枚举优先级队列——N 个 ConcurrentQueue<T> 桶，每桶对应一个枚举优先级。

★ 严格优先级：按枚举值升序扫描桶（值小先出），同优先级桶内 FIFO。

★ 无锁入队：ConcurrentQueue<T> 内部无锁实现。

★ lock-free 出队：扫桶 TryDequeue(out T)，单消费者接近 wait-free。

★ 适用场景：优先级是少量离散枚举值（如 4~16 级）。任意可比优先级用 SkipListPriorityQueue<T>。

★ 零分配：入队复用 ConcurrentQueue<T> 的分段池；等待复用 AsyncManualResetEvent 池化 source。

DequeueAsync(CancellationToken)

异步出队——空队列时挂起直到有元素入队或取消。

★ counting-semaphore MPMC（多生产者多消费者）：Enqueue(T, TPriority) 每入一项 Release 一许可， 本方法先 WaitAsync 消费一个许可再 TryDequeue(out T)。

★ 无 fast-path 偷项：许可数 == 可取项数，消费许可后 TryDequeue(out T) 必中 （无孤儿许可累积→无 SemaphoreFullException；多消费者逐项公平唤醒→无惊群）。 许可可用时 WaitAsync 立即返回，故单消费者性能与 fast-path 相当。
