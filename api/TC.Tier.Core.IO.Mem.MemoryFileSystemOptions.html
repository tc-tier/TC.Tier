    Class MemoryFileSystemOptions

    内存文件系统选项（medium-protocol-and-parity-design §6——继承 FileSystemOptions 基类）。

    ★ 基类三成员在此介质全部生效：Access（包络执法）、QuotaBytes（物理占用计费——G3 改名归一， -1 = 无上限）、Label（P4 落位）。

    ★ 用户决策维 = 内存预算（Sparse 省内存）vs 访问性能（Reserved 直址零分配）。
