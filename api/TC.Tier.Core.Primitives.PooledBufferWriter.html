Class PooledBufferWriter

Namespace
TC.Tier.Core.Primitives

TC.Tier.Core.dll

池化增长缓冲写器（IBufferWriter<T> 的租借形态）——背板数组经 ArrayPool<T> 租借、按需倍增（旧板归还），稳态零分配。

★ 与 BCL ArrayBufferWriter 的差别：背板不入 LOH 常驻——Rent/Return 生命周期显式 （Reset() 保留背板复用、Dispose() 归还池）；写完即发送的帧场景 （raft AppendEntries 条目区直写）由调用方持实例跨 await，发送完成后才可 Reset()。

★ 非线程安全（单写者——与 IBufferWriter 通用契约一致）。
