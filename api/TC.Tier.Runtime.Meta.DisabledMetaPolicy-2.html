Disabled meta 策略——no-op（不持久化 meta）。默认值。

所有读写/提交操作都是 no-op；Load 返回 false（无 meta）。适用于无数据/空盘/外部管 hints 场景。

public sealed class DisabledMetaPolicy<THeader, TPayload> : IMetaPolicy<THeader, TPayload>, IDisposable, IAsyncDisposable where THeader : struct where TPayload : struct
