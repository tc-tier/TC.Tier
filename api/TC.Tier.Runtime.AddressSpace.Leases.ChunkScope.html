chunk 视图 + 分段提交控制——完整迭代器模式（foreach / for / while 三态，）。

★ 普通struct（非 ref）——foreach/for 循环体内可 await（CopyChunksAsync 兼容）。

★ 几何属性沿用 RangeChunk 命名（SegId/SegOff/SegEnd/Length）； Commit()/Rollback() 显式分段终态（doneMask 保 exactly-once，重复调用安全）。

★ 消费方协议（三种等价写法）：

  • foreach (var chunk in lease) { IO(chunk); chunk.Commit(); }——pattern-based GetEnumerator，零分配
  • for (var i = 0; i < lease.ChunkCount; i++) { var chunk = lease[i]; IO(chunk); chunk.Commit(); }——索引器含物理门
  • while (iter.MoveNext()) { IO(iter.Current); iter.CommitCurrent(); }——原 while 模式保留
