Managed meta 策略——独立 IStorageEngine + 四段自描述块 + Magic/CRC 校验。

★ 统一布局：[统一 Header N B][内部水位线（结构化）][外部 opaque（实际用量）][统一 Footer CRC 4B]。

★ 自描述核心（设计决策 ）：header.PayloadLength = 水位字节数 + opaque 实际用量； 水线位置 = HeaderSize（固定）；opaque 范围 = 其后至 PayloadLength；footer 位 = HeaderSize + PayloadLength。 容量（可变的启动配置）零参与盘上几何——跨重启容量随便调，读侧全按盘上自述定位，水位无条件恢复。

★ 容量（MetaOpaqueBytes）只做写侧约束：opaque 写入上限 + 缓冲分配 + 引擎段几何。

★ CRC32C 覆盖 Header + 水位 + 实际 opaque（到 footer 前），存于 Footer。
