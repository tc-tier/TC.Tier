Core/Net 唯一的网络 IO 异常类型（Core.IO.FileIOException 同构先例——家族·网络层标准）： 传输面失败（目标未连/握手失败/连接失败/会话 Reset/流拒绝）的统一出口——InProcess/TCP 两介质同构，Socket 层错误不裸抛（IOException 是 BCL 底层类型，网络层契约 面一等类型）。

★ 铁律：不携带任何协议语义（raft/p2p 词汇）——协议语义由机制面在边界包装补充。

★ 派生自 IOException（BCL）——消费者可用单一 catch (IOException) 兜底； 底层原生错误（SocketException 等）以 InnerException 携带保留诊断。
