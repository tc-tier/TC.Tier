HyParView 挂载件（spec-12 §6 × §1 机制零特权——机制在自身命名空间实现挂载形态， 经 INodeMechanism 端口走与第三方/私有域同一挂载路径；装配四面零机制知识 （TCSG061 机器锁）的兼容形态）。

★ MountAsync：PeerController 构造 + StartAsync（内部口注册 0x02）→ seed 非空时 JoinAsync(seed)（有界等待——JoinWaitTimeout 兜底，seed 不可达 不挂装配）；seed 为空 = 部署种子自身（只启动不 JOIN——发现从种子扩散）。

★ Gossip 广播 opt-in（WithBroadcast(BroadcastOptions?)）：挂载时一并构造 SwarmBroadcast（视图提供者接控制器——一行委托，机制间零握手），随会员机制 同生命周期；Broadcast 挂载后为使用句柄（未开启 = null）。
