    Enum PreallocationMode

    预分配方式轴（IS-04 统一词汇——四介质同一套语义；缺省 = 现行行为）。

    Metadata：逻辑占位（稀疏——未写区域不占物理块；创建快、写时按需分配）。

    Full：物理占位（非稀疏——创建时物化全部空间，一次性成本显式化由部署方承担， 换运行时零分配抖动；生产数据库形态"raw + 预分配 + 非稀疏 + DIO"的预分配维度）。
