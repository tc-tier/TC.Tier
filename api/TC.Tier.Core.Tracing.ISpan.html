链路 span 契约 —— 一次操作的执行上下文（参照 OpenTelemetry ISpan / Datadog IScope）。

由 BeginSpan(string, SpanKind) 创建，Dispose() 结束 span（= EndSpan）。

典型用法：using var span = _tracer.BeginSpan("wal.append", SpanKind.Producer);

★ AOT 友好：纯接口 + 枚举，无反射/Emit。NullSpan 是零开销空实现。
