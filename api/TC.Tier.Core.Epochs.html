EpochProtectedVersionScheme

时代保护版本方案 (EPVS) 是允许对共享资源的安全并发访问的版本化方案。它使用底层的epoch框架来管理保护，并确保在保护线程时不会发生版本转换。EPVS维护可以被执行以在版本之间转换的状态机，并且它提供用于进入和离开保护、刷新保护以及执行具有临界区的状态机的方法。
