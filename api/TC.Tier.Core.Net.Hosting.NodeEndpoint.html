节点端点（spec-12 §11 装配产物——builder StartAsync 的返回值）： 传输完整面委托 + 机制生命周期归位（装配方持机制、随端点释放）+ 地址制直连的 对端身份（RemoteId——握手后才得知，§4.1）。

★ 完整面含内部挂载口（TC.Tier.Core.Net.Channels.ICoreProtocolPort 显式转发——raft/机制面 经端点挂载与直连传输同路径）；内层未实现 = 快速失败（机制宿主归 Core.Net）。

★ 生命周期：DisposeAsync 先机制（逆挂载序）后传输——单一收口。

SendRequestAsync(NodeId, byte, ReadOnlyMemory<byte>, RequestOptions?, CancellationToken)

请求回调发送（spec-12 §5.2——单请求 → 关联应答 → 超时；CorrId 传输生成）。

★ 目标未连 = 抛 NetIOException（调用方有应答期待，不静默浪费超时窗）； 注入丢弃 = 超时；取消传播；应答到达返回载荷（空应答合法）。

★ 投递语义缺省 at-most-once（单发 + 超时）；重传/确认 = 显式选择 （RetryPolicy——at-least-once）。

★ ValueTask 单次消费契约（await 恰一次）；参数校验（未连接/载荷超限/已释放） 在调用点同步抛（非 async 直通形态——调用方 try/catch 即达）。
