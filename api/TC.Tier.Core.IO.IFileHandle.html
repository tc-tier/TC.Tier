    Interface IFileHandle

    单个文件的访问与操作——Core/IO 数据平面（fd 模型 ∪ overlapped 模型，D7）。

    一个 IFileHandle 实例对应一个文件的一种打开语义（Access × Mode × Sharing × Hints）。

    ★ 磁盘实现：SafeFileHandle + RandomAccess（内含 DIO 对齐校验与逐句柄探测）。

    ★ 内存实现：槽代际寻址（open 时解析一次，热路径零字典开销）。

    ★ 位置语义并集：Write/Read(offset) 保持 pwrite/pread 无状态铁律（不读不推进游标）； 句柄同时内建生命周期游标（open 初始化、Append(ReadOnlySpan<byte>) 原子预留推进、Seek(long, SeekOrigin) 移动）。

    ★ FileExtra 平面（§3.6 终稿）：一份不透明附加数据 ≤MaxFileExtraBytes， 与 fs 级（IFileSystem.CreateFile(extra:)/Stat→FsEntryInfo.FileExtra）同平面互见。 心智模型：≤1.5K 的小文件——四成员即其 pread/pwrite/整写投影。

    Append(ReadOnlySpan<byte>)

    原子预留追加——Interlocked 预留游标区间后 pwrite 落地，返回实际写入偏移。

    ★ 同一句柄多线程 Append 无覆写、无撕裂（比内核 O_APPEND 更强且任何介质成立）。

    ★ 失败语义：预留不回滚（回退=吞噬他人预留），失败区间成为读零稀疏洞； 异常携带 ReservedOffset（预留落点），句柄不因失败废止。
