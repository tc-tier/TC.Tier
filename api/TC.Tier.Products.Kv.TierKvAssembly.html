Class TierKvAssembly

Namespace
TC.Tier.Products.Kv
Assembly
TC.Tier.Products.dll

TierKv 默认装配的 Settings 翻译面（public——[KvStore] 生成的封闭形态经此把 TierKvOptions 翻译为各族结构 Settings；显式层 TierKvBuilder<TKey, TValue> 工厂注入同用）。

★ 只建 Settings（纯配置类型，构建零副作用）——结构实例构造仍走闸门（开放泛型不落消费面， 生成封闭形态以派生肢构造）。

★ 引擎名派生：数据 = KvName+"-data"、索引 = KvName+"-index"（同卷异引擎名与 Ring 共栖）。

★ mem 介质不预分配物理段（TierWalBuilder 同款守卫——preallocate 触发大块 pinned 数组， POH 是进程全局堆，N 实例并发建段打爆 POH → native 挂死；mem 无磁盘对齐需求，稀疏按需零代价）。
