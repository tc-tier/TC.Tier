S3 客户端配置——endpoint/region/凭证/重试/超时/能力位声明。

★ 兼容云矩阵：同一实现换 endpoint/credentials 覆盖 S3/OSS(S3 兼容)/MinIO/R2/B2； COS 不承诺（独立 V5 签名，另议——remote-storage-s3 设计 §7.5）。

★ 能力位声明（Supports*）：S3 2023+/MinIO 当前版条件 PUT/DELETE 均 ✓（默认开）； 老兼容端点（部分 OSS 版本/老 MinIO）由部署方按实际关闭——能力位诚实表达，fencing 层据此降级。
