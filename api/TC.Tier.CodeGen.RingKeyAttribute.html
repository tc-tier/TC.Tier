KV Key 特化封闭注册标注（ring-generic-key-and-index-split 设计稿 §2）。

★ 消费方一行声明 [assembly: RingKey(typeof(OrderId))] → 生成器产出全套封闭薄类： RingOfOrderId : BlittableRing<OrderId> + HashOfOrderId : HashIndex<OrderId> + BTreeOfOrderId/SkipListOfOrderId（ctor 转发 + Create 工厂一步生命周期）。 开放泛型内核手写一次，封闭形态生成器产出——开放泛型不落消费面，无反射 MakeGenericType（AOT 干净）。

★ Type 形态（CodeGen.Abstractions 标注先例）；Key 不满足 unmanaged 约束生成器编译期报错 （非运行时炸）；IEquatable<TKey> 缺失由生成物的 CS0314 兜底。
