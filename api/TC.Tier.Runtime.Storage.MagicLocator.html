IStorageEngine 地址空间的魔术字方向性定位（不透明字节——零/非零全部是有效数据， 无任何格式/布局假设）。

★ 契约（使用方三输入，工具零假设）：只匹配传入的魔术值；方向性（需要最后=地址最大匹配点, 需要最小=地址最小匹配点）；范围由使用方给（格式知识剪小搜索域）；alignment 是扫描步进 速度提示——步进跳过的偏移不检查，使用方必须传自己格式的真实对齐（无对齐保证传 1）。

★ 两步定位协议：本类（引擎侧）按 magic 值扫描做粗锚点——返回精确匹配地址 + 所在页起点； 上层使用者（Log/Ring/Mirror 恢复）从锚点起结合自身格式精确查找记录边界（magic 只提名候选， 结构/CRC 才是裁决）。

★ 扩展方法形态（纯消费面算法——只吃 IStorageEngine 公开面，无引擎内部状态）： engine.Locate(...) 或静态形态 MagicLocator.Locate(engine, ...)。

★ 方向性 magic 定位（同步）。在 [from, to) 半开范围内按方向找 magic 匹配点。

from/to 自动收敛到 [MinAddress, AllocatedTail]（引擎已分配域——范围外的区域不可能有有效数据）。

public static MagicLocation Locate(this IStorageEngine engine, ReadOnlySpan<uint> magics, MagicDirection direction, LogicalAddress from, LogicalAddress to, int scanPageSize, int magicAlignment, MagicLocateStrategy strategy = MagicLocateStrategy.Linear)

Parameters

engine IStorageEngine

目标引擎。

使用方魔术值集合（可多值）。

direction MagicDirection

First=地址最小匹配点 / Last=地址最大匹配点。

from LogicalAddress

搜索范围起点（含）。

to LogicalAddress

搜索范围终点（不含）。

scanPageSize int

扫描读页步进（2 的幂，建议 = 使用方 PageSize）。

magicAlignment int

magic 对齐步进（使用方 record 对齐，2 的幂；无对齐保证传 1）。

Linear=保证正确逐页扫 / Monotone=页级二分（使用方断言含 magic 页单调）。

MagicLocation

定位结果。空范围 / 无命中 → NotFound。
