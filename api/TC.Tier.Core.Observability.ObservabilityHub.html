    Class ObservabilityHub

    可观测性聚合入口 —— TC.Tier 唯一可观测性接入点。

    ★ 外部配置一个 Hub，分发到各引擎/结构。底层组件只持 Hub 引用（或子视图），调用极简。

    ★ 默认零开销：不配置时用 Disabled 单例，所有 IsEnabled 返回 false。

    ★ 内部封装两级短路（Options.Enabled && sink/tracer.IsEnabled）+ 维度开关 + 采样率。

    ★ partial：ObservabilityHub.MetricsView + 分类视图（ObservabilityHub.StorageView/ObservabilityHub.LogView/ ObservabilityHub.IndexView/ObservabilityHub.SegmentAllocatorView）定义在单独 partial 文件中。
