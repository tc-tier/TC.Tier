协议级批量/管道（二期-E5 NETGAP-033）：把 N 个单项请求封装为一个请求帧 （一次往返摊薄 per-request 开销），应答同样批量回程（逐项 status + 载荷）。

★ 信封（自描述、帧头不动）：

请求  [count 4B][×N: len 4B + bytes]
应答  [count 4B][×N: status 1B + len 4B + bytes]   status: 0=ok, 1=error

★ 管道：批量请求之间天然并发（传输 CorrId 独立配对）——同链多批在途即管道。

★ 约束：批量域 handler 须同步应答（快进快出——deferred 应答不兼容批量聚合）； 单项上限/总量遵循帧 16MB 上界（Encode 超限抛）。
