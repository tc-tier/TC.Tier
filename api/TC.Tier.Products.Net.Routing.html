GroupReplicaRouter

GroupReplicaRouter——复制档通用组路由面（一个物理传输 × 一个协议域一实例）： 传输绑定 + 组分发 + 提案转发 + 状态封套四件事的公共单点，产品零重复。

★ 一个物理传输一个路由器（同进程多组共享——GetOrCreate(IProtocolTransport, byte, ILogger?) 惰性挂载）， 入站请求按组 ID 分发到对应 IGroupProposalHandler；出站 = ForwardAsync(NodeId, RaftGroupId, ReadOnlyMemory<byte>, CancellationToken) （把命令送达目标节点的提案面——目标非 leader 时回 NotLeaderHint，调用方重路由）。

★ 线格式（请求回调形态——CorrId 由传输承载）：请求 [GroupId 8B][命令字节] → 应答 [Status 1B][体]：Ok=[HasAddr 1B][Addr 16B][Index 8B]；StaleEpoch/Rejected=[Len 4B][UTF8]； NotLeaderHint=[Leader 16B]。状态字节值即 GroupApplyStatus——域内线格式稳定锚。

★ 组表 = 本地装配事实（Register(RaftGroupId, IGroupProposalHandler) 由 Builder 装配完成时挂载）；入站未装配组 = 确定性 Rejected 应答（组发现不归路由器——另一半在 gossip/静态配置）。
