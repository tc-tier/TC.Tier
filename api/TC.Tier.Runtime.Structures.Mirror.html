Namespace TC.Tier.Runtime.Structures.Mirror

Classes

MirrorBase

核心机制 partial：checkpoint 会话 + 读 + N=2 截断 + 2PC + Dispose。

MirrorSettings

MirrorBase 配置基类。

★ 引擎配置走 MainEngine（StorageEngineOptions，构造 = 配置）： Mirror 版本链是单段追加流——便捷构造默认 enableSegmentation=false + 稀疏按需增长。

★ N=2 轮替是固定策略（保留当前+上一 checkpoint，更老即收），不设配置项（spec §2.7）。

PagedMirror

PagedMirror——per-page 多链 checkpoint 镜像（统一帧格式，PerKey 链）。

★ 子类实现面（COORDINATION §4 铁律 10）：codec（PMVH/PMFT、CRC32C）+ 页门面 （WritePage/ReadPage——每页一个帧，走基类帧三拍）+ per-page 字典钩子。 机制（帧写入/走链恢复/嵌入 meta/N=2/2PC）全部在 MirrorBase。

★ v2 帧化：页 record 从定长整块（头存长度+padding）改为同族帧（双魔术值推导长度、 padding 退役、帧长任意字节边界）——两种镜像一套格式一套机制。

PagedMirrorSettings

PagedMirror 专属配置——页几何（每页一个 record，PageSize = 1 << LogPageSizeBits）。

WholeMirror

WholeMirror——整体单链 checkpoint 镜像（统一帧格式，Single 链）。

★ 子类实现面（COORDINATION §4 铁律 10）：codec（WMHD/WMFT、CRC64）+ 会话门面 （三拍直通基类帧原语）+ 单链钩子（链头推进/保留窗口）。机制（帧写入/走链/尾锚/嵌入 meta/ N=2/2PC）全部在 MirrorBase。

★ 写会话真流式：BeginSession → AppendChunk × N → EndSession——不知尺寸、零缓冲、 CRC64 边写边累积收官落尾（全程不需要知道总长）。

★ 生命周期：new + Initialize()（后台恢复）+ WaitForReady()。详见 src/TC.Tier.Core/docs/lifecycle.md。

WholeMirrorSettings

WholeMirror 专属配置（整体镜像，v2 流式帧——尺寸写尾时才知，无需预告）。
