池化的单次完成 IValueTaskSource<TResult>（带载荷版——PooledValueTaskSource 的泛化）： 每次 Rent(bool) 一个独立实例，SetResult(T) / SetException(Exception) 后归还复用。

语义与非泛型版逐条同源（完成先于注册协议 #PERF-002 / 单次完成守卫 / 双层池化 / 归还拒绝迟到完成 / CORE-03 注销），差异仅载荷经 ManualResetValueTaskSourceCore<TResult> 的结果通道传递（GetResult 原样返回）。

典型消费面：请求回调 pending 表——每请求 Rent 一个代替 new TaskCompletionSource（TCS 一次性 语义不可池化，本类型 Reset 后可复用）；await 终态经 OnCleanup 或显式 Return(PooledValueTaskSource<T>) 归还。
