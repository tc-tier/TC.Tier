NetworkImageTransfer

根空间镜像的 TCP 流式收发（raw-medium-and-conversion-design §9——网络发射端）。

★ 协议 TIN1：握手（magic "TIN1" | 版本 u16 | mode u8）→ 载荷 → 回执帧 （magic "TIN2" | 帧数 u64 | 原始字节 u64 | 聚合 CRC u32 | 状态 u8）。

★ 双向：同一 TCP 连接，发起端既可发送（Send）也可接收（ReceiveTo）——方向由调用者角色决定， 协议对称（对端另一角色运行互补方法）。

★ 校验：TCA1 逐帧 CRC + 尾对账之上，接收端回执回传摘要——发送端可确认对端落盘一致。

★ Raw 档（mode=Raw，#492）：连续卷整卷字节镜像——载荷为 [源长 u64] + 数据帧 （[len u32][payload][crc32 u32]，1 MiB 分块逐帧 CRC）+ 终结帧（len=0）； 回执 CRC 字段 = 聚合载荷 CRC（Structural 档 = 摘要字段 CRC——模式分轨语义）。 源侧 EnterMaintenance(WriteOperations) = 传输窗口只读冻结；接收端 EnterMaintenance(AllOperations) + 容量预检（不足写前拒绝，目标零字节受损）+ 长度对账 + OnMirrorCompleted 重建内存元数据。

★ v1 边界：单连接单传送（无续传/多路复用——续传为帧级断点的后续增强，台账 RM-06）； Restore 要求 seekable 流的适配在此解决（网络流经 NetworkImageTransfer.RetargetableStream 中转）。
