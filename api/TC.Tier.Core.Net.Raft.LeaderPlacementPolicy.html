优先 Leader 放置策略（二期-F7——DDR-F7）：偏好序声明 + 观测循环 + 既有 TransferLeadershipAsync(NodeId, CancellationToken)（编排面——选举协议零改动）。

★ 迁移三要素（齐备才发起，防抖）：① 当前 leader 偏好位置劣于某存活 voter； ② 该成员已追平（leader 视角 matchIndex == commitIndex——数据安全搬迁）； ③ 无在途转让（同目标未完成不重复发起——转让超时由引擎自愈回退）。

★ 偏好序语义：列表顺序即优先级（越前越优）；不在列表中的 voter 视为最低优先； 成员宕机 = 追平判定自然跳过。witness 因 IsFullVoter 门天然不可承接（F2）。
