Gossip 广播帧头（37B——[MsgId 16B][Origin 16B][Ttl 1B][PayloadLength 4B]，payload 紧随）。 MsgId = 广播身份（去重键——全网同消息至多投递一次）；Origin = 最初广播者（中继不变—— 投递面语义）；布局知识声明式单点（生成 codec 出偏移/读写/尺寸——零手写字节序）。
