Namespace TC.Tier.Core.IO.TierVolume

Classes

TierVolumeCarrier

载体描述（raw-medium-and-conversion-design §2.1）——两种物理形态，一份逻辑布局。

★ 文件载体：OS 文件系统上的 `.tier` 单文件（跨进程锁 = 伴生锁文件）。

★ 设备载体：裸块设备/裸分区（跨进程排他 = 卷级独占）—— Linux：`/dev/...`（原生 open(2) + flock(LOCK_EX|LOCK_NB) + O_DIRECT）；

Windows（2026-08-26 补齐）：virtual:///dev/C:（卷 → \\.\C:，CreateFile share=0 独占 + FSCTL_LOCK_VOLUME 锁卷）或 virtual:///dev/PhysicalDriveN（物理盘 → \\.\PhysicalDriveN， 独占句柄排他）；NO_BUFFERING 直 IO + WRITE_THROUGH 写穿档（IS-03 同机制）。

TierVolumeFormatOptions

虚拟文件系统格式化选项（medium-protocol-and-parity-design §6——继承 FileSystemOptions 基类）。

★ 一词制：基类 QuotaBytes 即供给（原 CapacityBytes——New 时刻物化， 位图按此预留）；Label New = 写入 superblock。

TierVolumeFs

位图 partial——空间事实的真相源（§2.3 铁律 / §3.1 统一块空间）。

★ 容量成比例（1 bit/块）、格式化时静态定长——是几何不是台阶（§3.1）。

★ v1 分配 = 起点提示 + 线性扫描 first-fit（分配是元数据路径非数据热路径——§3.4 单锁足够）。

TierVolumeOpenOptions

虚拟文件系统打开选项（medium-protocol-and-parity-design §6——继承 FileSystemOptions 基类）。

★ 原布尔 ReadOnly 并入基类 Access（G2 三态化—— Read = 只读打开[dirty 降级形态]，ReadWrite = 缺省；Write = 纯摄入——虚拟卷无此概念，Open 即拒）。

★ 基类 QuotaBytes = 挂载收紧：有效上限 = min(quota, 供给)（§5.3）； Label = Open 校验（不符即抛 fail-fast）。
