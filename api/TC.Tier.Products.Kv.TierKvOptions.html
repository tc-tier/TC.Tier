RingPageSize

Ring 页池页大小（字节，2 的幂）。默认 256KB——增量 flush 的写穿粒度： 页越大单次 flush 拷贝越多（结构默认 32MB 巨页会让 Committed 档单次退化到 ms 级； 1MB=44µs、256KB=9µs，实测矩阵见 perf/tierkv.md）。与 RingMemorySize 联合约束页槽数（须低于 Ring 校验上限）。
