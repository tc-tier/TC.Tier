    Interface ILeaseSource

    段表对操作 lease 的契约——整体级 {Kind}Commit/Rollback + 段查询 + 建段协调。

    ★ 继承 IExtentLeaseSource（操作 lease 也需要区间级操作）。

    ★ LeaseBase / CompactLease 持此接口引用。

    ★ 重载区分粒度：有 int segId = 单 Chunk（ExtentLease 级），无 segId = 整体（LeaseBase 级）。

    AcquireExtentsForLease(LogicalAddress, LogicalAddress, byte, ExtentLease[])

    遍历 [start, end) 跨段区间，逐个占住（AcquireExtent）填到 buffer——零中间分配（无 List/rangesBuf）。

    ★ lease Reset 核心调用：一次遍历完成"算 chunk + 占住 + 填 buffer"，消除 GetExtentRanges 的 List 分配。

    ★ buffer 须 ≥ GetExtentCount(LogicalAddress, LogicalAddress) 返回值。部分失败时 lease 的 catch 回滚已占 chunk。
