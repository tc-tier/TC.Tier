段表对操作 lease 的契约——整体级 {Kind}Commit/Rollback + 段查询 + 建段协调。

★ 继承 IExtentLeaseSource（操作 lease 也需要区间级操作）。

★ LeaseBase / CompactLease 持此接口引用。

★ 重载区分粒度：有 int segId = 单 Chunk（ExtentLease 级），无 segId = 整体（LeaseBase 级）。
