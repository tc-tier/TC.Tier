Class UnifiedCrc64

Namespace
TC.Tier.Core.Primitives

TC.Tier.Core.dll

CRC-64（ECMA-182）增量计算器——System.IO.Hashing.Crc64 的自研化替代（算法/输出逐位一致）。

★ 配套 UnifiedCrc：一次性计算走 UnifiedCrc.ComputeCrc64（ThreadStatic 复用本类实例）； 跨 chunk 累积走 UnifiedCrc.CreateCrc64() + Append + UnifiedCrc.FinalizeCrc64()。

★ ≥16B 输入走 PCLMULQDQ/ARM AES 向量折叠（性能与官方同）；短输入/无指令平台走 256 项查表。
