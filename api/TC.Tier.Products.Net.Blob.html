BlobSwarmBlockSource

Blob 块源（#436 件一——holder 侧）：DP 节点把本地已导入对象挂上 Swarm 分发面。

★ v1 形态 = 显式 AttachAsync(LogicalAddress, CancellationToken) 预载（对象经 ITierBlob.GetAsync 一次读入 进程内缓存——不可变对象缓存安全）：Swarm 取块接口是同步面而 Blob 读会话是异步面， 流式 seek 切块留待读会话异步化（阶段二，按带宽实测驱动）。缓存内容不动整对象—— Checksums/Manifest 首次实算后按 Id 缓存（"任何 holder 可重算"权威语义）。

★ 只读源：TryWriteBlock 不覆写（默认实现）——不可变对象修复走整对象重拉（定案 3）。

BlobSwarmImporter

Blob 导入会话（#436 件二——拉取侧）：清单发现 → K=1 顺序下载 → 流式灌 Blob 写会话。

★ 会话纪律（2PC 形态）：开始即开会话，任一块失败/源耗尽 = Abort 清理半成品上抛； 全块灌完提交（对象表登记 ObjectId）→ Announce 登记 → 多源从字面成立。

★ 顺序性 = K=1 顺序拉取（Blob OpenWrite 顺序追加——多源无序块无法落位，定案 4）； 零暂存、O(单块) 驻留（流式纪律）。

★ 修复粒度 = 整对象重拉：反熵检出漂移 = 删本地 + 本导入幂等重导（ObjectId 不变）。

BlobSwarmManifest

Blob 内容 ↔ Swarm manifest 派生（#436 件一配套——不可变对象假设下 manifest 是 ObjectId 的 稳定函数）。

★ Id 承载 = LogicalAddress 16B 原序直拷（SegId 4B LE + Extension 4B LE + Offset 8B LE—— 结构布局原序，与 raft 覆点承载形态互不重叠）。
