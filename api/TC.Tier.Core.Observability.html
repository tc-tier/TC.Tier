Namespace TC.Tier.Core.Observability

Classes

ObservabilityHub

可观测性聚合入口 —— TC.Tier 唯一可观测性接入点。

★ 外部配置一个 Hub，分发到各引擎/结构。底层组件只持 Hub 引用（或子视图），调用极简。

★ 默认零开销：不配置时用 Disabled 单例，所有 IsEnabled 返回 false。

★ 内部封装两级短路（Options.Enabled && sink/tracer.IsEnabled）+ 维度开关 + 采样率。

★ partial：ObservabilityHub.MetricsView + 分类视图（ObservabilityHub.StorageView/ObservabilityHub.LogView/ ObservabilityHub.IndexView/ObservabilityHub.SegmentAllocatorView）定义在单独 partial 文件中。

ObservabilityHub.IndexView

Index 结构维度视图 —— Find/Insert/Upsert/Delete/Scan。

ObservabilityHub.LogView

Log 结构维度视图 —— Append/Commit/Truncate/Recover。

ObservabilityHub.MetricsView

三原语公共视图 —— 镜像 IMetricsSink，带 IsEnabled 短路。

ObservabilityHub.SegmentAllocatorView

Segment 分配器维度视图——段表的 Segment 分配/释放/FreeList 深度（段表专用，非通用 Allocator 原语； 命名如实标明作用域，勿再泛化）。

ObservabilityHub.StorageView

Storage Engine IO 维度视图 —— Read/Write/Flush/Compact/Reclaim/Throttle。

ObservabilityOptions

可观测性配置聚合 —— 追踪 + 指标两信号各自独立配置（对齐 OTel TracerProvider + MeterProvider）。

★ 注入引擎/结构，由工厂分发到各子视图。

★ 日志不由 Options 控制——日志的级别/过滤由注入的 ILoggerFactory 实现自行决定。

★ 默认零开销：new ObservabilityOptions() → 追踪关、指标关。
