    Interface ISnapshotWriteSession

    写会话（双 buffer flush 流水线）——GB/TB 流式写核心。 双 buffer：A 满启动异步 flush(A) 立即切 B；B 满 await flush(A)（通常已完成）再 flush(B)。 CPU 序列化与磁盘 IO 并行，消除单 buffer 串行停顿。
