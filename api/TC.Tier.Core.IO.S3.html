Namespace TC.Tier.Core.IO.S3

Classes

EnvironmentCredentials

环境变量凭证源（每次调用重读——外部 STS 刷新器改环境变量即生效）。

S3ClientOptions

S3 客户端配置——endpoint/region/凭证/重试/超时/能力位声明。

★ 兼容云矩阵：同一实现换 endpoint/credentials 覆盖 S3/OSS(S3 兼容)/MinIO/R2/B2； COS 不承诺（独立 V5 签名，另议——remote-storage-s3 设计 §7.5）。

★ 能力位声明（Supports*）：S3 2023+/MinIO 当前版条件 PUT/DELETE 均 ✓（默认开）； 老兼容端点（部分 OSS 版本/老 MinIO）由部署方按实际关闭——能力位诚实表达，fencing 层据此降级。

S3ObjectStore

S3 兼容对象存储——IObjectStore 默认实现（SigV4 自写、零外部依赖）。

★ 一个实现覆盖全部 S3 兼容云（S3 / OSS(S3 兼容端点) / MinIO / R2 / B2——换 endpoint/credentials 即达）； COS 不承诺（V5 签名差异大，独立实现另议——设计 §7.5）。

★ 寻址：path-style（{endpoint}/{bucket}/{key}）——MinIO/自建端点标准形态。 canonical URI 与请求 URL 同编码器生成（S3 特例：不归一化不二次编码）。

★ 重试矩阵（§9.9）：幂等操作（GET/HEAD/PUT/DELETE/List/UploadPart）对 5xx/429/网络抖动指数退避重试； CreateMultipartUpload 不重试（可能双开会话）；Complete 重放安全（NoSuchUpload → NotFound，桥层回读校验）。

★ 线程安全：HttpClient 并发共用（连接池复用）；multipart 会话独立无共享态。

S3ProtocolBuilder

s3 协议构建器（medium-protocol-and-parity-design §2.2 两级注册表的二级开放轴）—— spec network:///s3/host[:port]/bucket/prefix → S3ObjectStore + RemoteFileSystem 全栈组装。

★ 依赖方向合法：IO.S3 → Core（注册表在 Core，实现在此——引用本程序集即自动注册， ModuleInitializer 挂载，消费方零代码）。

★ spec 映射：endpoint=host[:port]（tls 缺省 https，tls=0 → http——本地 MinIO 类）； vhost/region → S3ClientOptions；prefix → KeyPrefix；spill=local:///…→Spill.ToDisk、 spill=memory:→Spill.ToMemory（G7 收编：单一概念两形态）；cred=env:NAME → 环境变量 NAME （值格式 accessKey:secretKey——引用永不携值）。

StaticCredentials

静态凭证（部署期固定密钥——MinIO 自建/专有云典型）。
