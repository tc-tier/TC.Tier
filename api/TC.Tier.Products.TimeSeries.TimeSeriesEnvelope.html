Class TimeSeriesEnvelope

Namespace
TC.Tier.Products.TimeSeries
Assembly
TC.Tier.Products.dll

TierTimeSeries 样本 envelope（tc-tier-timeseries-spec §2 产品层协议——TQE1 同族版本化变长头）。

布局（"TTS1"+flags 共 5B 头 + 双槽 16B）： [Magic 4B "TTS1"][Flags 1B][Timestamp 8B][Seq 8B?] + 原 payload。

★ flags：bit0=HAS_SEQ（客户端序槽有效——乱序同刻消歧/幂等的预留面）； 其余位预留（压缩标记/系统样本——定案⑦ Gorilla 系后续迭代，接口零变更）。

★ Timestamp = UTC Ticks，envelope 槽自述完整 ts（record key 只做分类）； 恢复对账 resolver 经本头读回 ts（非时序 record magic 不符 → 不入索引）。
