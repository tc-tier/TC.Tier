Span 序列化器接口——TValue 类型化的非 blittable 档（tierkv-orchestration-design.md §2）。

★ 通用对象序列化：调用方注入实现，TierKvValue<T> 经此将 T 序列化为字节流写入 Ring、 读回时反序列化。与 blittable 直拷档互补（blittable 走 MemoryMarshal.Read/Write 零分配快路径）。

★ 契约：GetMaxSize() 返回值上界（TierKvValue 用于预分配缓冲区）； Write(Span<byte>, in T) 必须写入 ≤ GetMaxSize() 字节并返回实际写入长度； Read(ReadOnlySpan<byte>) 从源 span 反序列化（长度由调用方传入实际 record value 长度）。

★ [TierValue] 源生成器（设计稿第三档——独立一笔）将为此接口自动发射实现： attribute 声明 → 生成器产出 XxxSerializer : ISpanSerializer<Xxx>。
