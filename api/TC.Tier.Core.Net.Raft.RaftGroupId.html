Raft 组标识（二期-C1 §3.1——Multi-Raft 组路由的组键）：8B 小端无符号整数，线上以 [GroupId 8B] 固定宽前缀承载于 Raft 家族协议域（0x01/0x03/0x04）载荷首部 （§2.1 统一组路由——无特例、无双轨）。

★ Empty（0）为默认组——同样带前缀；非零组由产品/元数据层分配 （Net 只承载与路由，spec 组语义归产品）。8B 取值空间消除元数据层 ID 碰撞焦虑， 每消息 8B 开销可忽略（帧头 16B v1 不动的既定前提下载荷内前缀为最小入侵面）。
