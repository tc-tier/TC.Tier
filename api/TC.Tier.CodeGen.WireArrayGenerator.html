[WireArray] 源生成器（spec-12 §10 E1）——变长集合线编码：[定长前缀字段…][Count 4B][item×N]。

★ 布局 = 声明序：非数组字段按声明顺序构成定长前缀（cursor 累积，零偏移知识—— 字段顺序即线顺序），数组字段承载变长区（byte[] = 字节块；T[] = 项数组，T 为基元整型或 标注 [BinaryLayout] 的 struct——项大小经其生成的 StructSize 表达式获得， 本生成器不重算别家布局）。

★ 生成 XxxCodec.Encode(Span<byte>, in T) → int / TryDecode(ReadOnlySpan<byte>, out T) → bool—— 计数、位置、字节序全部生成物，消费层零手写。

★ 防御上限（MaxCount）显式声明：Count 超限 = TryDecode false——畸形报文拦截。

★ 诊断 TCSG045-048（数组字段数/元素类型/上限/构造函数形态）——拼错即炸。
