组搬迁编排器（二期-F5——DDR-F5）：把某成员从组内迁出至目标节点的四步编排—— 目标入组 → 等追平 → leader 迁移（若在源）→ 源出组。

★ 数据面归 Fs（裁定③——镜像/迁移通道归 Fs 既有能力）；本面只做时序调度 + 配置变更——日志复制追平是缺省搬迁形态，镜像通道由装配方在入组前预热（接口不变）。

★ 恢复语义（F3 变更链同款）：每步都是已提交的合法配置态；任一步失败保留 中间态，重调幂等续走（已入组跳过、已迁 leader 跳过、已出组跳过）。
