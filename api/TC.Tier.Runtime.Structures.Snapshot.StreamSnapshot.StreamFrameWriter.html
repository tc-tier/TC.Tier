    Class StreamSnapshot.StreamFrameWriter

    流式帧写入器。[Header 14B][Data][Footer 28B（Magic+TotalLength+EntryCount+Crc64）]。 CRC64 incremental 覆盖 Header + Data + Footer 前 20B（流式边写边累积，Complete 收官）。 多帧：Complete 后 ResetFrame，可再开新帧。
