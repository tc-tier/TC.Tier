MetadataMetaHeader

MetadataBase 的 meta 水位 Header（§5.7 Meta 三段式，12B 纯规范，永不变）。

水位进 Payload（MetadataMetaPayload），Header 只有规范字段。对齐 Log/Ring。

MetadataMetaPayload

MetadataBase 的 meta 水位 Payload（版本链两端 + tx seq）。

开启 meta 时 O(1) 查 HighestVersionAddress/LowestVersionAddress 做截断定位；关闭扫盘按版本号定位。

MetadataRecordFields

VersionedMetadata record 业务字段包（供 codec 读写 header 时传参，对齐 RingRecordFields）。

MetadataRecoveryHints

MetadataBase 恢复 hints（与 Log/Ring/Blob 的 hints 完全独立，各结构各自定义）。

Interfaces

IMetadataCodec

MetadataBase 版本 record codec 接口——注入 MetadataBase，支持替换（对齐 Log 的 ILogCodec / Ring 的 IRingCodec）。

★ 私有嵌套 sealed 类实现（VersionedMetadata.Codec），JIT 去虚化。

IPersistencePolicy

数据落盘策略——决定 Write() 后何时触发 Persist（落盘）。 与 meta 4 模式正交（meta 是水位持久化，这是数据 record 落盘时机）。
