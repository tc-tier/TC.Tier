Class TimeSeriesRollup

Namespace
TC.Tier.Products.TimeSeries
Assembly
TC.Tier.Products.dll

降采样 Rollup 算子（tc-tier-timeseries-spec §6 定案⑤——组合糖）： 读源序列 [fromTs, toTs) 按 windowTicks 分窗聚合 → 逐窗写目标序列（窗起点, 8B double）。

★ 形态 = 原子算子（对标 InfluxDB CQ/Timescale caggs 的算子面——连续调度归业务 cron/后台任务）； 多档级联（1m→10m→1h）= 目标序列再作源（值编码 8B double 定档，组合律成立）。

★ 窗口对齐 = epoch 对齐（windowTicks 整数倍，向下取整）——级联档窗口天然嵌套。
