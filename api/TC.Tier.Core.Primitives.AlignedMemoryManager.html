    public AlignedMemoryManager(int size, int alignment = 4096, bool zeroed = false, bool lockPhysicalMemory = false)
    Parameters
    Type Name Description
    int size

    需要分配的逻辑字节数
    int alignment

    物理对齐要求，必须为正且是 2 的幂
    bool zeroed

    是否清零内存。大部分调用方构造后立即覆写，建议 false；安全敏感场景开启。
    bool lockPhysicalMemory

    是否锁定到物理内存（禁止swap，低延迟IO场景开启）
