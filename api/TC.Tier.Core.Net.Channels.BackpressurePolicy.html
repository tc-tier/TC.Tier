背压策略（二期-D5 NETGAP-014/016——请求 pending 满载时的域级行为；产品按域声明， 缺省 FailFast 保持既有语义）。

public enum BackpressurePolicy : byte

Fields

Degrade = 2

满载降级——pending 满立即抛 RequestDegradeException（携带降级语义 的失败面——产品可据此fallback/限流告警，区别于失控 fail-fast）。

FailFast = 0

缺省——pending 满 = 立即抛 InvalidOperationException（fail-fast， 调用方并发失控或应答缺失的快速失败面）。

Priority = 3

高优先级——共享池满仍可入（预留预算 RequestPriorityReserve 槽位内准入； 超预留回落 fail-fast）。适合管理面/心跳类关键域。

Queue = 1

有界排队——pending 满时等待槽位释放（≤ 队列等待上限 RequestQueueWait； 超时回落 fail-fast 抛）。适合可容忍短时延迟的域。
