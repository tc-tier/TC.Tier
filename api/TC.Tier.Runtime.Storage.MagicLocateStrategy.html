★ 前置条件（使用方断言，错了漏检责任在使用方）：含 magic 页单调—— Last 要求含 magic 页集合是前缀（出现后不再消失，稠密 record 流成立）； First 要求是后缀（出现之前全无，前缀洞形态成立）。Log/Ring 恢复满足； 零富集/多洞布局不满足——用 Linear。
