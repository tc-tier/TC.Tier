指标接收器底层原语契约 —— 三原语模型（对齐 OpenTelemetry Meter）。

外部监控适配器（Prometheus / Datadog / OTel）只需实现这三个方法 + IsEnabled， 不必认识任何上层语义方法（OnRead/OnCheckpoint 等）。

★ 三原语语义：

  • Counter单调递增计数（发生次数：throttle、bufferFull、error）。
  • Histogram值分布（延迟、大小：read latency、payload size、duration）。
  • Gauge瞬时值，可增可减（当前队列深度、内存使用率、freeList 深度）。

★ 默认实现 NullMetricsSink：全空方法 + IsEnabled=false，热路径零开销。

★ public —— 供上层注入实现，对接外部监控系统。
