    Class SkipListIndex<TKey>

    SkipListIndex 主存储格式布局 partial——机制归基类（TC.Tier.Runtime.Structures.SortedIndex.SortedIndexBase`1.TryDump 编排/ 版本链/后台循环/帧走链），本件只实现格式：32B 几何 + 物化。

    ★ 帧体布局：[几何 32B]——currentLevel(4) pad(4) entryCount(8) headAddr(16)。 节点本就写时持久化在自持引擎（节点变更即 WriteNodeToEngine）——帧不写节点流， 物化=head arena 落位 + 塔顶锚点 + 计数；层 0 链节点访问经 GetNode 引擎读回自愈。
