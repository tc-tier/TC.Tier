VersionedMetadata 版本 record header（统一三段式 + 版本链独有字段）。

布局：[规范字段 14B][PreviousVersion 16B][Version 8B][Crc 4B] = 42B，Payload 在 Header 之后，无 Footer（CRC in Header）。

★ PreviousVersion/Version 是版本链指针，跟数据一起（数据头包裹的一部分，不是 meta）。

源生成器（[BinaryLayout]）生成 VersionedMetadataHeaderCodec（偏移/小端/CRC 编译期生成）。

[BinaryLayout(Features = BinaryLayoutFeatures.All)]
