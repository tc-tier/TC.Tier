    Namespace TC.Tier.Core.Tracing

    Classes

    NullSpan

    零开销空 Span —— NullTracer.BeginSpan 返回此单例。

    所有方法空实现，Dispose 空操作。可安全用于 using var span = tracer.BeginSpan(...)。

    NullTracer

    零开销空 Tracer —— 默认实现。

    ★ BeginSpan(string, SpanKind) 返回 Instance（非 null，避免 using 块 NRE —— 修复原 NullTracer 返回 null 的缺陷）。

    ★ Current 恒返回 null（不维护 AsyncLocal 栈，零开销）。生产路径默认用此实现。

    TracingConfig

    链路追踪配置（独立于指标/日志，对齐 OTel TracerProvider）。

    ★ 三信号各自独立配置 —— 追踪、指标、日志是完全不同的可观测信号， 不应共用一个开关。每个信号有自己的 Enabled + 策略。

    ★ 默认 Enabled=false（零开销）：热路径只读 1 个 volatile bool（IsEnabled），false 时 不调 BeginSpan、不分配 span、不调 Dispose。

    ★ 采样策略：即便启用追踪，高吞吐热路径（每秒数十万次 Append）全采 span 会拖垮性能。 SampleRate 控制采样频率（100=全采，10=采10%，0=不采）。

    Interfaces

    ISpan

    链路 span 契约 —— 一次操作的执行上下文（参照 OpenTelemetry ISpan / Datadog IScope）。

    由 BeginSpan(string, SpanKind) 创建，Dispose() 结束 span（= EndSpan）。

    典型用法：using var span = _tracer.BeginSpan("wal.append", SpanKind.Producer);

    ★ AOT 友好：纯接口 + 枚举，无反射/Emit。NullSpan 是零开销空实现。

    ITracer

    链路追踪器契约 —— 完整 span 体系（从零设计）。

    ★ 完整 span 体系（参照 OpenTelemetry/Datadog），从零设计，非修补：

    - BeginSpan(string, SpanKind) 创建 span，返回 ISpan（Dispose=EndSpan）；

    - Current 暴露 AsyncLocal 当前 span（Datadog 模式，避免层层传参，子 span 自动关联父 span）；

    - public（与 IMetricsSink / ILogger 一致，供上层注入）。

    ★ 默认实现 NullTracer：BeginSpan(string, SpanKind) 返回 Instance（非 null，避免 using NRE），零开销。

    ★ AOT 友好：纯接口 + 枚举 + AsyncLocal，无反射/Emit。
