RingMetaPayload

RingMeta Payload 区结构化首部——持久化层 5 指针(LogicalAddress) + LastCommittedSeq + LastPreparedSeq + OverflowTail + CommittedTail。

★ 全 LogicalAddress（base.md §2.3/§2.7）——大小不参与地址，根除位打包毒点。

★ [BinaryLayout] → 源生成器生成 RingMetaPayloadCodec.Write/Read。

★ HeadAddress/SafeHeadAddress（内存水位层）不存——恢复时从 BeginAddress 重建。

★ ClosedUntilAddress（簿记层）不存——恢复时初始化为 SafeHeadAddress。

★ CommittedTailAddress（D2 Abort 回退点）：Prepare 开窗时的尾快照——本轮悬干数据之前的 最后边界（= 上一已确认提交对应的尾）。Abort/恢复裁决据此 TruncateSuffix 回退；Empty = 无待回滚窗口。

★ public：IRingMetaPolicy 为 public 接口，参数/返回类型须同级可见（CS0050/CS0051）。

参见 base.md §2.7。

IRingSnapshot

Ring 快照接口——上层导出/导入 Ring 页池数据的统一抽象。

★ pull/push 分离：Reader/Writer 分别对应上层 pull/push 模式，支持 GB/TB。

★ 对齐 WAL 的 Snapshot 范式（pull/push 模式，IAsyncDisposable）。

IRingSnapshotReader

Ring 快照读取器——上层 pull 数据从 Ring 导出（快照导出用）。

★ 页级流式：caller 每次 Read 只取自己 buffer 大小的数据，处理完再 Read 下一块，支持 GB/TB。

★ 冷热透明：内部按 FlushedUntilAddress 分流热区（内存页池取）/冷区（设备读），对外统一连续字节流。

★ 压缩/保存是上层的事：caller 在自己的 Read 循环里套压缩 Stream / 文件 / 网络，Ring 输出原始字节。

★ 对齐 WAL 的 SnapshotReader 范式（pull 模式，IAsyncDisposable）。

参见 base.md §2.10。

IRingSnapshotWriter

Ring 快照写入器——上层 push 数据填回 Ring 页池（快照导入用）。

★ 页级流式：caller 每次 Write 推送一块数据，Ring 逐段填入页池，支持 GB/TB。

★ 填完所有数据后须调 Complete 推进 TailAddress 到 end。

★ 对齐 WAL 的 SnapshotWrite 范式（push 模式，WriteAsync + CompleteAsync）。

参见 base.md §2.10。
