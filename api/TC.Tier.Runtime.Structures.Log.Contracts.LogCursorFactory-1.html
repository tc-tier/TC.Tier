扫描游标工厂委托签名（LogBase owner + 物理区间）。

★ snapshotMode（spec-10 根治）：Consistent = 构造期区间段共享锁全程持有（快照隔离——恢复扫描等 单线程场景）；DirtyRead = 逐段短暂共享锁（游标锁——读写并发常态，复制读等高频路径；异步轨以 drain worker 段独占锁提供物理互斥，见 SequentialReader 头注释）。默认 Consistent（既有行为）。

★ leasePages：页租借（零拷贝读——2026-08-29 性能：apply 读热路径 ToArray 消除）。 false（默认）= 换页即还池（CurrentPayload/CurrentPayloadMemory 禁跨 MoveNext 持有）； true = 游标持有全部已读页至 Dispose（CurrentPayloadMemory 有效至 Dispose——批量切片直用的前提）。

public delegate TLogCursor LogCursorFactory<out TLogCursor>(LogicalAddress startAddress, LogicalAddress endAddress, bool verifyCrc = false, SnapshotMode snapshotMode = SnapshotMode.Consistent, bool leasePages = false) where TLogCursor : ILogCursor

Parameters

startAddress LogicalAddress

扫描起点 LogicalAddress（default = data 区头；entry 地址则游标自动跳过其前字节）。

endAddress LogicalAddress

扫描终点 LogicalAddress（default = 结构自定的可靠落盘水位）。

verifyCrc bool

true = 逐条校验记录 CRC；false = 仅整页 PageFrame CRC 校验。默认 false。

snapshotMode SnapshotMode

一致性模式：Consistent（快照隔离）/ DirtyRead（游标锁）。默认 Consistent。

leasePages bool

true = 页租借（换页不还池）；false = 换页即还池。默认 false。

Returns

TLogCursor

打开的扫描游标实例（类型参数约束为 ILogCursor）。
