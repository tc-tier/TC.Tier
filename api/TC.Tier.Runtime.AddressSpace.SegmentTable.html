    AdvanceAddress(LogicalAddress, long)

    从 start 前进 length 字节得到新地址（跨段进位）。

    ★ 只前进：length < 0 抛异常（回退调 RetreatAddress(LogicalAddress, long)）；== 0 返回 start。

    ★ 返回的 Extension 恒为 0——调用方须显式保留 start.Extension。

    ★ 区间表示统一（设计决策）：半开 [start, end)——end 是"已前进字节之后第一个位置"， 恰好填满一段时停驻 (segId, segLimit)（段末边界规范形），不产出 (segId+1, 0) 哨兵形态。 (N, 0) 只保留"段首字节/原点"身份；段末只有一种写法——与 RetreatAddress 互为精确镜像， 与扫盘恢复尾 (seg, GrowthLimit) 同形。

    WaitSegmentReady(int, ILogger?)

    等待段物理就绪（物理门）——零锁：volatile 查状态 + 单向闩分片等待（§6.1）。

    ★ 协调协议：先查状态（volatile）→ 等闩（Set 只发生在 Empty→Ready/Broken/Invalid 单向迁移）→ 醒后单一出口判定——双检零竞态，无锁序、无释放窗口（X-1 死锁家族结构性消灭）。

    ★ 非 Empty 态闩必已开（三出口都 Set）——进入慢路径的终态段零阻塞直达出口判定， 无需前置 Broken/Invalid 检查（单一检查点）。

    ★ 有界放弃协议保留：1s 分片 / 5s 周期告警 / 60s 超时抛出（worker 病理性停摆的安全闹）。
