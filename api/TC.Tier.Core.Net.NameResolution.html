Classes

DnsAnswer

查询结果——记录集 + 聚合 MinTtl + 安全位结论（#498 诉求 6/7）。

★ 聚合 MinTtl：CNAME 跟随链各跳 TTL 取最小（缓存有效期的权威口径）；记录集为空且 ResponseCode=NxDomain = 负缓存形态。

★ 确定性：同应答字节 → 同结果（记录保持应答节顺序，零顺序扰动）。

DnsSecurityStatus

安全位结论（security-aware stub 契约，RFC 4033 §8——#498 诉求 7）：stub 不做签名验证链 （RRSIG/DNSKEY/DS/NSEC·NSEC3 为递归解析器职责，永久 Non-goal），把验证结论位完整外显 即履行客户端契约——AuthenticatedData = 递归层已验证的可信标注，消费方按需采信。

DnsStubResolver

security-aware DNS stub resolver（#498——RFC 1035/2782/6891 客户端面全契约，零外部依赖叶子位）： 查询（SRV/A/AAAA）＋解析＋TTL 缓存＋EDNS0/安全位。

★ 传输：UDP:53 首选；TC 置位 → TCP 重试；超时 + Retries 次（指数退避）；多 server 轮询容错（每次尝试轮换下一个——ServFail/超时跟随）。

★ 名展开（K8s CoreDNS 形态）：绝对名（尾点）直查；相对名按 ndots 阈值——点数 ≥ 阈值 先绝对后 search，否则先 search 后绝对（resolv.conf / Windows 网卡配置自举）。

★ CNAME 跟随：深度上限 8，聚合 MinTtl（链上各跳取最小）；SRV 不跟随（RFC 2782：SRV 属主 不得为别名）。记录集保持应答节顺序——同应答字节 → 同结果。

★ Non-goal（#498 永久排除）：DNSSEC 签名验证链与递归迭代解析（stub 以 AD 位消费递归层 验证结论——DnsSecurityStatus）；DNS server 面；mDNS/LLMNR/DNS-SD 组播族。

DnsStubResolverOptions

DNS stub resolver 选项（#498——零外部依赖叶子位的全部旋钮；缺省值即 K8s CoreDNS 兼容形态）。

★ 名字即全部：全部具名属性、无选项回调；null = 操作系统自举（resolv.conf / 网卡配置， 见 DnsStubResolver）。

Structs

DnsMessageHeader

DNS 报文头（RFC 1035 §4.1.1——12B 大端）。布局声明一次（FieldOffset），读写全为 DnsMessageHeaderCodec 生成物——零手写偏移（generators.md 反模式 1）。

★ Flags 是位域打包（QR/Opcode/AA/TC/RD/RA/Z/AD/CD/RCODE）——位面语义归 TC.Tier.Core.Net.NameResolution.DnsHeaderFlags 常量族，布局面只承载原始 16 位。

DnsRecordPrefix

资源记录固定前缀（RFC 1035 §4.1.3——10B 大端；RR 与 OPT 伪记录共用形态）。

★ OPT（RFC 6891）：Class 字段承载 UDP 载荷声明、Ttl 字段承载扩展段（DO 占最高位）、 NAME 恒为根——名字不入本布局（记录名走压缩指针游标，见 TC.Tier.Core.Net.NameResolution.DnsWire）。

DnsSrvRecord
