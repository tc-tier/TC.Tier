HyParView 会员管理器（spec-06 全量 × spec-12 §6 机制面形态映射——视图维护/随机游走 JOIN/ PhiAccrual 故障检测；gossip/成员消息走数据报形态，UDP bearer 天然）。

★ 挂载（§3.5）：构造收 IProtocolTransport 端点，StartAsync() 经 TC.Tier.Core.Net.Channels.ICoreProtocolPort 内部口注册 HyParView（0x02）—— 与使用方协议域同一分发路径（机制零特权）；传输生命周期归装配层。

★ 语义纪律（spec-06 审查定案）：HyParView = 会员管理，不含广播——广播是独立 dissemination 组件（IBroadcast）。

★ 线程契约：消息处理（介质分发上下文，多路）+ 周期循环（心跳/shuffle 单 worker）—— 视图变更全部经 TC.Tier.Core.Net.P2P.PeerController._lock 串行化（内存操作 µs 级，锁短临界）； 视图维护的尽力发送经 TC.Tier.Core.Net.P2P.PeerController._sends（TaskSink——同步完成零分配快路径，异常组内观测， Dispose 有界排空）。
