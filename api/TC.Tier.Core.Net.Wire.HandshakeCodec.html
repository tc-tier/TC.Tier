握手帧载荷编解码与协商规则（spec-12 §3.3 三步握手）。

★ 载荷布局 [BinaryLayout] 声明（HandshakeInit/HandshakeAck， 32B/31B 定长——NodeId@0 为 §2 一等结构嵌套件 16B 原序直拷；ClusterTag 4B 集群归属在 握手期交换（身份不变、归属可变——错集群 fail-fast，§3.3））；读写由生成的 HandshakeInitCodec/HandshakeAckCodec 产出，本层只持协商语义 （版本区间/保留位/安全档校验、交集规则）。

★ 三步时序/超时/防降级判定归连接层（spec-12 §3.3/§3.4）。
