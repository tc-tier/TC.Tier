    Class KeyComparer<TKey>

    默认 key 比较器：XxHash64 哈希 + Comparer/EqualityComparer.Default 比较。

    ★ XxHash64 是 .NET 内置高性能非加密哈希（System.IO.Hashing），同款用于上层 HashKV。

    ★ 对 unmanaged TKey 按 SizeOf<T>() 字节做 hash，分布均匀。
