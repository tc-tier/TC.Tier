请求回调帧薄层（spec-12 §5.2——Request 0x08 / Response 0x09，载荷 = [CorrId 8B][payload]）。

★ 布局知识在 CorrelationPrefix（[BinaryLayout] 声明式生成——零手写 字节序/偏移）；本层只做前缀拆装与载荷切片边界。

防御：载荷 < 前缀尺寸 = 违规帧（返回 false——丢弃 + 计数，不致命）。
