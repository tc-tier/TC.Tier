    LoggerExtensions

    Logger 扩展方法 — 提供 LogInformation/LogWarning/LogError 等便捷方法。

    ★ 零开销短路：每个重载内部先 IsEnabled(LogLevel) 再格式化——调用方无需手写 IsEnabled。 0~3 参数用强类型重载（关闭时不装箱、不分配、不格式化）。

    ★ 超过 3 个参数走 params 重载：内部仍判 IsEnabled（不格式化），但数组+装箱在调用点 发生（进扩展之前）——正确性无恙，仅热路径值得先手动 IsEnabled 保护或拆成 ≤3 参。

    ★ 格式化用 Format(IFormatProvider, string, object)（仅 IsEnabled true 时）。 命名占位符（{name}）按参数顺序映射为数字索引，兼容 M.E.Logging 惯例。

    ILogger

    Kernel 日志接口 — 替代 Microsoft.Extensions.Logging.ILogger。

    内核代码通过此接口记录日志，默认 NullLogger 零开销。

    ★ 简化签名：去掉 M.E.Logging 的泛型 TState + formatter——内核只做文本日志， 结构化参数由 LoggerExtensions 的扩展方法用 string.Format 先格式化再传入。
