QoS 管理器（二期-E4 NETGAP-032——每协议/每来源配额与限流）： 两级令牌桶——域级聚合 + 域内按来源（租户=来源节点语义）；TryAdmit 双级全过才准入。 策略运行期可变（重复 Set = 重置桶）；未设置 = 不限流（既有语义）。
