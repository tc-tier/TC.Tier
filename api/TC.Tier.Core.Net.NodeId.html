节点身份——网络核心协议一等结构（spec-12 §2：自定义结构，不借任何 BCL 类型当协议身份）。

★ 组合 Opaque16（16B 不透明字节串——布局唯一真源在彼处，本类型是身份 语义包装）：字节原序直拷、无端序解释，协议字节与运行时类型解耦。

★ [BinaryLayout] 标注 = 线协议标准嵌套件（spec-12 §10）——生成的 NodeIdCodec 委托 Opaque16Codec（小端直写承载字 = 字节原序直拷）；本类型内零 BinaryPrimitives、 零偏移字面量。

★ 布局零语义：不塞集群号/代次/预留位——集群归属是握手字段，fencing/代次是 raft 任期 与证书的事；预留字段 = 想当然。

★ 宽度 128-bit：集群身份第一性质 = 免协调不碰撞，128-bit 使其永不成议题 （身份每消息一次、从不每条目，字典基数 = 节点数）。

★ Guid 只在边界：配置/数据库/第三方互操作的适配转换；线上与存储无 Guid 概念。

★ 安全绑定文本 = ToString() 文本形式（mTLS 档 SAN nid:<hex32> URI 条目；KeyPair 档 NodeId↔公钥钉扎绑定——spec-12 §3.4）。
