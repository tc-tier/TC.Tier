BinaryLayoutAttribute

标记 struct 由 BinaryLayoutGenerator 生成 XxxCodec。

★ 要求 struct 用 [StructLayout(LayoutKind.Explicit, Size = XxxSize)] + [FieldOffset]。

★ 总字节数从 [StructLayout].Size 取值（源生成器交叉校验 Size vs 字段偏移和，不一致报 TCSG001）。

★ OrFlags/IsEmpty/Features 控制额外生成能力（替代 [GenerateOrFlags]/[GenerateIsEmpty]）。

★ 字段类型支持：基元（uint/ushort/ulong/long/int/byte）+ 同底层类型的 enum + 嵌套 [BinaryLayout] struct。

★ 嵌套 struct（如 SegmentAddress）：字段类型必须是标了 [BinaryLayout] 的 struct——源生成器 靠收集表查其大小（标记驱动：只有收集表里的 struct 才支持嵌套）。未标记的 struct 作嵌套字段报 TCSG002。

★ readonly struct：Read 方法用 MemoryMarshal.Read 整体反序列化（object initializer 不能赋值 readonly 字段）。

★ 字段校验特性 [ValidEquals]/[ValidRange]/[ValidHasFlags]/[ValidNonDefault] 保留在字段上独立声明。

BinaryLayoutGenerator

[BinaryLayout] 源生成器——为每个标注的 struct 生成静态 Codec 类（StructSize / 字段常量 / 单字段读写 / 整体 Write/Read / Validate），全部 BinaryPrimitives 小端收口。

★ 两阶段管道：收集阶段（ParseLayout）只产出各 struct 自身元数据并报编译期诊断， Collect() 后全部 struct 在表里，生成阶段（EmitCodec）才查表解析嵌套引用——前向引用安全。

CommandArgAttribute

位置参数标注——CLI 有序、HTTP 取自路由段（#435 命令源生成）。

类型集 = string/bool/int/uint/long/ulong/double/decimal/Guid/DateTimeOffset/任意枚举 及其 Nullable<T> 形态（编译期 TryParse 直调零反射）；有 C# 默认值 = 可选，无 = 必选。

CommandAttribute

叶子命令标注——命令组内的一条子命令（#435 命令源生成）。

方法签名契约：返回 ValueTask<T>/Task<T>/ValueTask/Task/T/void 全支持； CancellationToken 参数框架注入不参与绑定；其余业务参数必须标注 CommandArgAttribute / CommandOptionAttribute / CommandBodyAttribute 之一。

CommandBodyAttribute

请求体标注——复杂类型参数 = HTTP body JSON 反序列化、CLI 读 stdin 全量字节（#435 命令源生成）。

★ 一个命令最多一个 body 参数（多个 = TCSG059）；GET 命令禁 body（TCSG058）。

★ AOT 契约：消费方以标准 [JsonSerializable] partial context 声明复杂类型清单， 生成的 CLI/HTTP 入口接收 JsonSerializerContext——生成代码 GetTypeInfo(typeof(T)) 查表非反射（生成器间不互喂，context 由消费方手写一次收口）。

CommandErrorAttribute

业务异常 → HTTP 状态码映射（#435 命令源生成）。

组级声明全组适用、方法级就近覆写。生成器按继承深度排序生成 catch 链（最派生优先）； 未声明的异常 → 500 兜底。消费方经 WriteError(int, Exception) 模式匹配自家异常提取错误码——零反射。

CommandGenerator

CLI 解析器发射（CommandGenerator 产物一）： Run/RunAsync 逐级组路径匹配 → 绑定 → 直调；WriteHelp/CompleteNext/CommandPaths 数据面。

CommandGroupAttribute

命令组标注——组嵌套子命令的组节点（#435 命令源生成）。

★ 根不根由结构位置判定：声明在别的 [CommandGroup] 类内 = 嵌套组（内节点）， 最外层 = 根组。根组 Name = 宿主 CLI 分发 token 与 HTTP 路由首段， 不作为 CLI 参数匹配（git/docker 形态——用户输入从根子级开始）；嵌套组 Name = CLI/HTTP 路径段。

任意深度嵌套；命令方法 = [Command] 标注的方法。

CommandOptionAttribute

具名选项标注——CLI --name value / -x value、HTTP 取自 query（#435 命令源生成）。

类型集同位置参数；解析即按长名归一，短名仅作输入别名。布尔选项支持 --flag 裸形态。

ConstantRegistryAttribute

标记常量类为常量注册表——ConstantRegistryGenerator 编译期防冲突 + 区间助手生成（spec-12 §10 E3）。

★ 重复值检测（恒生效）：类内全部整型 const 字段的数值两两相异—— 重复即 TCSG040 Error（FrameKind/ProtocolId/Channel/特性位常量防冲突，声明即锁死）。

★ 区间助手（可选，Zones 声明）：生成 static bool 谓词(value) 注入本类（类必须声明 partial）——谓词参数类型 = 类内整型 const 的统一类型 （混合整型类型报 TCSG044）。

ConstantRegistryGenerator

[ConstantRegistry] 源生成器（spec-12 §10 E3）——常量注册表编译期防冲突 + 区间助手。

★ 重复值检测（恒生效）：类内整型 const 字段数值两两相异，重复报 TCSG040 （FrameKind/ProtocolId/Channel/特性位常量表手写漂移的编译期锁死）。

★ 区间助手（Zones 声明）：谓词注入本类 partial（与 TierFs 生成 partial TierFs 同构）； 声明格式/区间值域/类声明形态/值域可判性违规分别报 TCSG041-044——拼错即炸，fail-fast。

KvStoreAttribute

TierKv 封闭注册标注（tierkv-design.md §0.1/§4 W1——开放泛型产品类的封闭消费面，[RingKey] 同款先例）。

★ 消费方一行声明 [assembly: KvStore(typeof(OrderKey), typeof(Position))] → 生成器产出 封闭形态 TierKvOfOrderKeyPosition : TierKv<OrderKey, Position>：ctor 转发 + CreateAsync 工厂（默认装配 + 生命周期一步到位）+ 内嵌派生 Ring/索引实现（派生肢获得构造权，开放泛型零构造）； formatter 按 TValue 自动发射（byte/byte[]/ROM<byte>/unmanaged 零代码，D6/D7 裁定）—— 其余 TValue 必须显式 Formatter（编译期校验，缺失 = 编译期报错非运行时炸）。

★ 主索引两层并存（§0.1）：IndexKind = 编译期缺省声明（生成器发射 DefaultOptions）； 运行经 TierKvOptions.IndexKind 覆盖（显式胜出）——CreateAsync 全三族索引实现齐备可路由。

★ TKey 约束校验：不满足 unmanaged → 生成器编译期报错；IEquatable<TKey> 缺失由生成物 CS0314 兜底（[RingKey] 同款）。

KvStoreGenerator

[KvStore] 生成器（tierkv-design.md §0.1/§4 W1——开放泛型产品类的封闭消费面，[RingKey] 同款先例）。

★ [assembly: KvStore(typeof(TKey), typeof(TValue))] → 一行声明产出封闭形态： TierKvOfKeyLeafValueLeaf : TierKv<TKey,TValue>（ctor 转发 + CreateAsync 工厂一步生命周期 + 内嵌派生 Ring/索引实现——派生肢获得 protected internal 构造权，开放泛型零构造）。 formatter 按 TValue 自动发射（byte/byte[]/ROM<byte>/unmanaged 零代码，D6/D7 裁定）； IndexKind 标注缺省发射 DefaultOptions（运行 Options.IndexKind 覆盖——显式胜出）。

★ 编译期校验：Key 不满足 unmanaged → TCSG021；TValue 无可用 formatter（非内建覆盖面且未声明 Formatter）→ TCSG022；Formatter 未实现 IValueFormatter<TValue> → TCSG023 （消费方未引用 Products 时接口符号不可解析——跳过该校验由生成物编译错误兜底，IEquatable 缺失同款 CS0314）。

MediumOptionsAttribute

★ string 形态（硬约束：Core 引用本程序集，标注不可反引 Core 的 StorageNature 枚举）—— 生成器对未知值编译期报错（拼错即炸，fail-fast）。

NetworkProtocolAttribute

RingKeyAttribute

KV Key 特化封闭注册标注（ring-generic-key-and-index-split 设计稿 §2）。

★ 消费方一行声明 [assembly: RingKey(typeof(OrderId))] → 生成器产出全套封闭薄类： RingOfOrderId : BlittableRing<OrderId> + HashOfOrderId : HashIndex<OrderId> + BTreeOfOrderId/SkipListOfOrderId（ctor 转发 + Create 工厂一步生命周期）。 开放泛型内核手写一次，封闭形态生成器产出——开放泛型不落消费面，无反射 MakeGenericType（AOT 干净）。

★ Type 形态（CodeGen.Abstractions 标注先例）；Key 不满足 unmanaged 约束生成器编译期报错 （非运行时炸）；IEquatable<TKey> 缺失由生成物的 CS0314 兜底。

RingKeyGenerator

[RingKey] 生成器（ring-generic-key-and-index-split 设计稿 §2——开放泛型的封闭注册，TierFs P-c 同款先例）。

★ [assembly: RingKey(typeof(T))] → 一行声明产出全套封闭形态： RingOfT : BlittableRing<T> + HashOfT : HashIndex<T> + BTreeOfT/SkipListOfT（ctor 转发 + Create 工厂 一步生命周期）。每个具体 Key 只声明不开发；开放泛型不落消费面（三索引 ctor 已收 protected internal 同闸门）。

★ 编译期约束校验：Key 不满足 unmanaged → TCSG020 报错；IEquatable 缺失由生成类 CS0314 兜底。

SpecParamAttribute

spec 参数标注（§3）——贴在 TierSpec 的参数属性上，DSL 生成器据此派生 builder 方法集 （方法集 = 参数表——单一事实源的机械执行；参数 × 介质归属与可重复性在此声明）。

TierFsGenerator

TierFs 构造面生成器（spec-typed-frontend-and-generator-design）：

★ P-a 重载族：[MediumOptions] 标注 → TierFsTypedOverloads.g.cs—— 每（options 类型 × 动词）发射类型化重载（人不再手写重载族——漂移源消灭）。

★ P-c 协议注册：[NetworkProtocol] 标注 → ModuleInitializer 注册代码 （替代手写 TierFsS3ModuleInitializer——加协议 = 实现接口 + 标注，注册自动）。

★ 标注一律 string 形态（Core→Abstractions 既有方向，不可反引 Core 类型）； 未知本性/动词编译期报错（TCSG0xx——拼错即炸）。

★ ★ 外部协议导出配方（设计决策定稿——Tier 通用导出协议机制）： 第三方协议程序集（任意命名，如 Contoso.Storage.S3）三步行接入，全部在项目配置内：

  1. csproj 声明导出意图（与 AssemblyInfo.cs 等价——编译时合成程序集特性）： <AssemblyAttribute Include="TC.Tier.CodeGen.TierProtocolExportedAttribute" />
  2. 实现类标注协议身份：[NetworkProtocol("myproto")] class MyBuilder : ITierProtocolBuilder （引用 CodeGen.Abstractions 特性定义 + TC.Tier.Core 接口）
  3. 直接编译——本生成器在消费方编译里扫描带 TierProtocolExported 标记的引用程序集（asm.GetAttributes()——零误扫非协议程序集）， 生成 TierFsExternalProtocolRegistration（ModuleInitializer——消费方加载即注册）。 消费方 TierFs.Open("network:///myproto/…") 直接可用，零反射、NativeAOT 安全。

关注点分离：类型级 [NetworkProtocol] 标注协议身份（本地 ModuleInitializer 注册）； 程序集级 TierProtocolExported 声明导出意图（外部桥精确扫描）。

TierProtocolExportedAttribute

★ 程序集级协议导出标记（设计决策——Tier 通用协议导出机制）： 协议程序集（TC.Tier.Core.IO.S3 或外部第三方）在程序集上标注本特性 = 声明 "本程序集导出网络协议"——TierFsGenerator 在消费方编译里只深入带此标记的 引用程序集找 NetworkProtocolAttribute 类型，生成注册桥。

★ 关注点分离：类型级 NetworkProtocolAttribute 标注协议身份 （协议键 + 实现类——协议程序集自身编译时本地 ModuleInitializer 注册）； 程序集级本特性声明导出意图（供外部桥精确扫描——零误扫非协议程序集）。

★ 无参标记——语义即"本程序集含 [NetworkProtocol] 导出"。第三方协议程序集加一行 [assembly: TierProtocolExported] 即被消费方自动发现（零反射，NativeAOT 安全）。

ValidEqualsAttribute

字段必须 == 指定常量。用于规范字段（MagicValue/Version/Flags 等）。

ValidHasFlagsAttribute

位掩码包含校验：字段必须包含 mask 的所有位（(field & mask) == mask）。 用于 Flags 这种"基线位必含 + 运行时可叠加动态位"的字段（如 entry meta 标记、末页标记）。

ValidNonDefaultAttribute

字段必须非默认零值。用于"必填任意非零值"语义。

ValidRangeAttribute

字段必须在 [min, max] 范围内。用于有界数值字段（PayloadLength/Length 等）。

WireArrayAttribute

标记 struct 为变长集合线编码（spec-12 §10 E1——[Count 4B][item×N]： 基元整型 / 标注 [BinaryLayout] struct 项 / byte[] 字节块）。

★ 布局 = 字段声明序：非数组字段构成定长前缀（声明顺序即线顺序——加字段 = 加一行声明， 位置由生成物累积，零偏移知识）；恰一个数组字段承载变长区，永远在前缀之后。 构造函数参数序 = （前缀字段声明序 + 数组字段）。

★ 生成 XxxCodec.Encode(Span<byte>, in T) → int（返回写入长度）与 TryDecode(ReadOnlySpan<byte>, out T) → bool——计数、位置、字节序全部生成物， 消费层零手写字节序与偏移。

★ 嵌套项（标注 [BinaryLayout] struct）的项大小经其生成的 StructSize 获得—— 嵌套元素布局须开 StructSize。

★ 防御上限显式声明：Count > MaxCount = TryDecode false（畸形报文拦截）。

WireArrayGenerator

[WireArray] 源生成器（spec-12 §10 E1）——变长集合线编码：[定长前缀字段…][Count 4B][item×N]。

★ 布局 = 声明序：非数组字段按声明顺序构成定长前缀（cursor 累积，零偏移知识—— 字段顺序即线顺序），数组字段承载变长区（byte[] = 字节块；T[] = 项数组，T 为基元整型或 标注 [BinaryLayout] 的 struct——项大小经其生成的 StructSize 表达式获得， 本生成器不重算别家布局）。

★ 生成 XxxCodec.Encode(Span<byte>, in T) → int / TryDecode(ReadOnlySpan<byte>, out T) → bool—— 计数、位置、字节序全部生成物，消费层零手写。

★ 防御上限（MaxCount）显式声明：Count 超限 = TryDecode false——畸形报文拦截。

★ 诊断 TCSG045-048（数组字段数/元素类型/上限/构造函数形态）——拼错即炸。

WireMemberAttribute

变长成员的防御上限显式声明（缺此标注的变长成员报 TCSG052）。 两种实参形态等价：[WireMember(8)]（位置）/ [WireMember(MaxCount = 8)]（命名——等号只绑可写属性）。

WireMessageAttribute

标记抽象基类为线消息族根（spec-12 §10 E2——消息族编码：[Tag 1B][根字段声明序][子类字段声明序]）。

★ 族根声明公共前缀字段（全体子类共享）；直接派生子类各标 WireMessageTagAttribute 携带 tag。生成 XxxCodec.Encode(msg) → byte[] / TryDecode(ReadOnlySpan<byte>, out msg) → bool 与 tag 常量（Tag子类名）——tag 判别、公共前缀、字段序、字节序全部生成物。

★ 成员支持：bool/基元整型（小端）、标注 [BinaryLayout] struct（嵌套件）、 byte[]/ReadOnlyMemory<byte>（blob：[Len 4B][bytes]）、数组/列表 of 上述与 ReadOnlyMemory<byte>（[Count 4B][item×N]，blob 项为 [Len 4B][bytes]）。

★ 未知 tag / 截断 / Count 超上限 = TryDecode false（畸形报文拦截；变长成员上限经 WireMemberAttribute 显式声明）。

WireMessageGenerator

[WireMessage] 源生成器（spec-12 §10 E2）——消息族线编码： [Tag 1B][根字段声明序][子类字段声明序]。

★ 族根（[WireMessage] 抽象类）声明公共前缀字段；直接派生子类各标 [WireMessageTag]。 生成 XxxCodec：Encode（tag 判别 + 全字段编码）/ TryDecode（未知 tag/截断/超上限 = false）/ tag 常量（Tag子类名 同源）。

★ 成员类型支持集：bool/基元整型（小端）、标注 [BinaryLayout] struct（嵌套件—— 项大小经其生成 StructSize）、byte[]/ReadOnlyMemory<byte> blob（[Len 4B][bytes]）、 数组/列表 of 上述与 ReadOnlyMemory<byte>（[Count 4B][item×N]，blob 项 [Len 4B][bytes]）。 变长成员必须 [WireMember(MaxCount)] 显式声明防御上限。

★ 诊断 TCSG050-053（tag 重复/成员类型不支持/变长成员缺上限/孤立 tag）——拼错即炸。
