TierQueue——本地持久队列（tc-tier-queue-spec：P0 核心流 + P1 消费组全量）。

★ 组合配方（Ring 骨架）：RingOfQueueKey（数据真相源）+ 组注册表 VersionedMetadata （{name}.groups——组名 + 定格配置）+ 每组一个 VersionedMetadata（{name}.group.{g}——位点/代次 原子提交域）。组 = 独立持久位点 + 独立投递簿记（pending 纯内存）。

★ 治理（spec §8.2 定案①）：Enqueue 前积压检查（MaxBacklogBytes）——Block（默认，有界等待）/ Reject / EvictOldest（fence 最慢组，显式 ResetGroupAsync 续命）。

★ 队列级 P0 兼容面（DequeueAsync/AckAsync/GroupCursor）委托 "$default" 组——地址档基线语义 （无 token 无 fencing）；token 档（fencing/deliver-once）经 CreateConsumerAsync(string)。

★ 线程模型：多生产者并发（Ring tail 串行）；组内 Dequeue/Ack/Claim 经组 _gate 串行；组间并行。

★ 复制面（tierqueue-replicated-spec §8）：显式实现 ITierQueueReplicationPort （不出现在公共面——复制状态机经端口驱动确定性核心；端口方法串行调用契约，apply 管道单 worker 满足）。
