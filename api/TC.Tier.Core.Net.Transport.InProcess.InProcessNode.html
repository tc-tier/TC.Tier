进程内节点传输端点（spec-12 §7 InProcess 介质——IProtocolTransport 完整面实现， 与 ClusterTransport（TCP）消费面零差别）：协议域注册/数据报收发/对端观测。

★ 派发：发送方上下文直排（handler 同步回调 + 异常隔离——回调异常不外泄到发送方， 尽力送达语义与 TCP 读循环同构）。

★ 生命周期：注册即活（Start() 为形态面幂等占位）；Dispose = 从枢纽注销。
