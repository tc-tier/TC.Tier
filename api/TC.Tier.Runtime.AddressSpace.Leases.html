Namespace TC.Tier.Runtime.AddressSpace.Leases

Classes

AppendLease

Append lease 协议——追加写（占位 + 推进游标）。终态收敛：推 CommittedTail 到 End。

★ 物理门：**有**——Append 的全部 chunk（IO 与提交）都必须等物理段 Empty→Ready。

CompactChunk

Compact 操作的区间块信息——用于记录旧段和新段的状态，支持分阶段提交。

★ 互斥终态（设计文档 §5）：Replacement/Invalid 二选一、只能从 Pending 流转一次—— 重复/交叉调用 throw（fail-fast，对齐 SegmentScanEntry 强校验绊线制度）， "双未设静默跳过 / 双设静默丢一"两类非法态从类型上消灭。

CompactLease

Compact 操作 lease——不支持 chunk 分阶段提交，必须整体原子提交。

★ _extents + _chunks 数组走 ArrayPool（独立池化）。

★ 支持 Reset（池化复用）。

LeaseBase

lease 基类——公共机械（占住/多 chunk 协调/doneMask 终态仲裁/Dispose），不含操作类型语义。

★ 每个操作类型是独立的类型化 lease 协议（AppendLease/WriteLease/ ReclaimLease/ReclaimHeadLease/ReclaimTailLease）—— 类型即协议：终态收敛由子类 override FinalizeTerminalCore() 表达，不做 kind 字节路由 （复拆：五合一的单体 OperationLease 抹掉了类型协议边界，上层怎么修都修不干净）。

★ chunk 终态仲裁（doneMask）与 Extents 机械在基类——与操作类型正交。

LeaseFactory

lease 工厂——创建 + 可选池化 + 可选诊断。

★ Default：每次 new + 无诊断（生产推荐——零诊断开销）。

★ WithDiagnostics：每次 new + 有诊断（测试/调试——GetActiveLeases/ForceRelease 可用）。

★ Pooled：对象池复用（高频 Append/Write 零分配）。

★ 使用方选择模式——不改变 lease 协议语义。

★ 类型化 lease 协议（复拆）：每个操作类型独立 lease 类 + 独立池—— 池按类型分立（Append 高频、ReclaimTail 低频，互不挤占），工厂方法返回各自类型。

LeaseInfo

lease 信息（诊断/查询用）。

ReclaimHeadLease

ReclaimHead lease 协议——头部回收（跨段删 + ShrinkHead 推 MinAddress）。终态收敛：推 MinAddress 到 End。

ReclaimLease

Reclaim lease 协议——中间区间打洞回收（段表不变、段水位不变，只改区间状态）。整体级无段表副作用。

ReclaimTailLease

ReclaimTail lease 协议——尾部截断（ShrinkTail 退双尾水位）。终态收敛：双尾回退到 Start。

WriteLease

Write lease 协议——随机覆写（地址已知，目标区间 ≤ CommittedTail）。整体级无段表副作用。

★ 物理门：**有**（显式声明——目标段按定义已 Ready，门走快路径零开销，不靠隐式前提）。

Structs

ChunkScope

chunk 视图 + 分段提交控制——完整迭代器模式（foreach / for / while 三态，）。

★ 普通struct（非 ref）——foreach/for 循环体内可 await（CopyChunksAsync 兼容）。

★ 几何属性沿用 RangeChunk 命名（SegId/SegOff/SegEnd/Length）； Commit()/Rollback() 显式分段终态（doneMask 保 exactly-once，重复调用安全）。

★ 消费方协议（三种等价写法）：

  • foreach (var chunk in lease) { IO(chunk); chunk.Commit(); }——pattern-based GetEnumerator，零分配
  • for (var i = 0; i < lease.ChunkCount; i++) { var chunk = lease[i]; IO(chunk); chunk.Commit(); }——索引器含物理门
  • while (iter.MoveNext()) { IO(iter.Current); iter.CommitCurrent(); }——原 while 模式保留
ExtentLease

区间级操作租约——封装占住区间的三阶段协议（Commit/Rollback）。

★ 持 IExtentLeaseSource（段表接口）引用，不持 Segment 引用。

★ kind 隐藏在 _extentState byte 高 4 bit——Commit/Rollback 按 Source 分发。

LeaseBase.ChunkEnumerator

lease 区间块的 struct 迭代器——零分配，保留延迟模型。

★ 持 LeaseBase 引用，MoveNext 过类型化物理门后由 Current 产出 ChunkScope（几何 + 分段 Commit/Rollback）——foreach 完整迭代器模式。

Interfaces

IExtentLeaseSource

段表对 ExtentLease 的契约——单 Chunk 级 {Kind}Commit/Rollback。

★ ExtentLease 持此接口引用，按自己的 kind 调对应方法，零 switch 状态逻辑。

★ kind 隐含在方法名里——AppendCommit/WriteCommit/ReclaimCommit 等，调用方一看方法名就知道是什么操作。

★ 状态处理封装在段表实现里——AppendCommit 内部知道要 CompleteAndMerge + AdvanceMaxOffset，调用方不用管。

ILeaseSource

段表对操作 lease 的契约——整体级 {Kind}Commit/Rollback + 段查询 + 建段协调。

★ 继承 IExtentLeaseSource（操作 lease 也需要区间级操作）。

★ LeaseBase / CompactLease 持此接口引用。

★ 重载区分粒度：有 int segId = 单 Chunk（ExtentLease 级），无 segId = 整体（LeaseBase 级）。

ITrackedLease

lease 追踪接口——用于诊断和泄漏报告。

Enums

LeaseState

操作 lease 状态——CAS 守护。终态（Committed/RolledBack/Finalized）语义等价：Finalize 已收敛、Extents 已释放；Dispose 守卫只判 != Active。
