链路追踪器契约 —— 完整 span 体系（从零设计）。

★ 完整 span 体系（参照 OpenTelemetry/Datadog），从零设计，非修补：

- BeginSpan(string, SpanKind) 创建 span，返回 ISpan（Dispose=EndSpan）；

- Current 暴露 AsyncLocal 当前 span（Datadog 模式，避免层层传参，子 span 自动关联父 span）；

- public（与 IMetricsSink / ILogger 一致，供上层注入）。

★ 默认实现 NullTracer：BeginSpan(string, SpanKind) 返回 Instance（非 null，避免 using NRE），零开销。

★ AOT 友好：纯接口 + 枚举 + AsyncLocal，无反射/Emit。

public interface ITracer

Properties

Current

当前线程异步上下文的活跃 span（Datadog AsyncLocal 模式）。

BeginSpan 自动设为新 span，Dispose 恢复父 span。子方法无需传参即可拿到当前 span 添加标签/事件。

NullTracer 返回 null（无活跃 span）。

ISpan? Current { get; }

Property Value

ISpan

Remarks

★ AsyncLocal 模式：BeginSpan/Dispose 自动维护父子链，子方法无需传参即可拿到当前 span 添加标签/事件。

IsEnabled

是否启用追踪（热路径零开销的关键开关，参照 IKernelLogger.IsEnabled）。

NullTracer 返回 false → 热路径 if (_tracer.IsEnabled) 完全短路，不调 BeginSpan、不分配 span。

注入真实 tracer 返回 true → 配合 SampleRate 采样命中才 BeginSpan。

bool IsEnabled { get; }

Property Value

bool

Remarks

★ 热路径必须在 if (_tracer.IsEnabled) 内调用 BeginSpan，避免 NullTracer 也分配 span。

Methods

BeginSpan(string, SpanKind)

开始一个 span。返回的 ISpan 的 Dispose 结束 span。

新 span 自动关联到 Current（AsyncLocal 父子链）。

★ 热路径必须在 if (_tracer.IsEnabled) 内调用，避免 NullTracer 也分配 span。
