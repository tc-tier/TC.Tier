    Class VersionedMetadata

    版本化元数据（VersionedMetadata）——小数据元数据（meta 结构体 + cursor）的版本链存储。 内存工作副本（运行时同步零 IO）+ 磁盘版本链（事务回滚）+ 多版本保留（Abort 零 IO）。

    ★ 生命周期：继承 MetadataBase（实现 ILifecycle<THints>）——MetadataBase.Initialize 同步 void 启动后台恢复后立即返回，调用方用 IsReady/WaitForReady/事件观测等待。详见 src/TC.Tier.Core/docs/lifecycle.md。
