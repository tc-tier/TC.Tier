复制策略（spec-02 复制层配置化——条数/字节/时间三维度任一触发一次 AppendEntries 批量发送）。

★ 默认全零 = 立即推送（append 即通知发送、窗口 1 流水线）。

★ 三维度语义：

- BatchSize：单次 AppendEntries 批上限（条数维度，默认 1000——spec-02 §2 攒批形态）

- BatchWindow：攒批时间窗口（时间维度——窗口内到达的 append 合并为一次发送； 0 = 立即推。真实网络下摊销 RTT 的关键参数；进程内场景收益小）

- MaxBatchBytes：批字节上限（字节维度；0 = 不限）

★ 窗口判定粒度 = 状态机 tick（5ms）——窗口配置自由，到期误差 ≤ tick 周期。
