lease 工厂——创建 + 可选池化 + 可选诊断。

★ Default：每次 new + 无诊断（生产推荐——零诊断开销）。

★ WithDiagnostics：每次 new + 有诊断（测试/调试——GetActiveLeases/ForceRelease 可用）。

★ Pooled：对象池复用（高频 Append/Write 零分配）。

★ 使用方选择模式——不改变 lease 协议语义。

★ 类型化 lease 协议（复拆）：每个操作类型独立 lease 类 + 独立池—— 池按类型分立（Append 高频、ReclaimTail 低频，互不挤占），工厂方法返回各自类型。
