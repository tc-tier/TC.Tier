    Class TransactionLog

    默认事务日志实现——独立 commit record 文件 + DirectIO + 4K 对齐 + Magic/Crc + Flush 落盘 + 链式触发。

    ★ 设计（见 transaction-design.md §5）：

    - 物理：独立文件 + DisableFileBuffering(DirectIO) + 4K 对齐固定覆盖写

    - Commit：seq+1 → 算 Crc → DirectIO 写 + Flush（这一次 Write+Flush = 原子点）→ 链式触发参与者

    - Load：读固定块 → 校验 Magic/Crc → 返回 seq（空/损坏 = 0）

    开箱即用，上层 new 即可；或注入自定义 ITransactionLog 替换。

    LoadAndReconcile()

    ★ 恢复协调：Load commit record + 推进所有已注册参与者到已提交 seq。

    调用方须在调用前 Register 所有参与者（与 Commit 时相同的集合）。

    恢复判定：

    - committedSeq == 0（空盘/损坏）→ 所有有悬干的参与者 Abort

    - LastCommittedSeq < committedSeq → ConfirmCommitted(committedSeq)（正向：未同步推进）

    - LastPreparedSeq > committedSeq → Abort(LastPreparedSeq)（反向：超前悬干丢弃）
