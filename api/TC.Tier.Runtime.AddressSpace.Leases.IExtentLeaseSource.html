    Interface IExtentLeaseSource

    段表对 ExtentLease 的契约——单 Chunk 级 {Kind}Commit/Rollback。

    ★ ExtentLease 持此接口引用，按自己的 kind 调对应方法，零 switch 状态逻辑。

    ★ kind 隐含在方法名里——AppendCommit/WriteCommit/ReclaimCommit 等，调用方一看方法名就知道是什么操作。

    ★ 状态处理封装在段表实现里——AppendCommit 内部知道要 CompleteAndMerge + AdvanceMaxOffset，调用方不用管。
