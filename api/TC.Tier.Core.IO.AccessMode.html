访问三态（medium-protocol-and-parity-design §2.5/§5.2）——一个三值概念，三个平面： 空间（FileSystemOptions.Access）、文件（FileOpenOptions.Access）、映射（Map API）。

★ 空间平面即总上包络：句柄/映射构造期校验 ⊑ fs.Access，越包络即抛、不构造。

★ 本枚举为目标词汇先行落位；P3 完成 AccessMode 改名与 AccessMode 并入。
