Class NetClientBuilder

Namespace
TC.Tier.Core.Net.Hosting
Assembly
TC.Tier.Core.Net.dll

地址制直连装配器（spec-12 §11——客户端预设：缺省不监听，可开监听=对称节点；客户端/服务器 无固定模式——装配预设可覆写，§4.2）。

★ Connect 后对端身份握手才得知（§4.1 地址制——有地址者拨号；目标未连 = NetIOException 快速失败）；RemoteId 携带。

★ 注册面：协议域/请求回调/流接受面启动前注册（对端推流/回调到达即服务）。 身份/安全档形态同 ClusterBuilder。
