Interfaces

ICheckpoint

Checkpoint 门面——主引擎只认这个接口，不感知内部 Coordinator 实现。

★ 设计决策（，用户）：**默认提供扫描，自定义存储需要自己注入**——引擎默认装配 扫盘只读切面（TC.Tier.Runtime.Storage.Checkpoint.ScanCheckpoint：HasSnapshot 恒 false、Writer 返 NoopWriter 接口占位、 Reader 扫盘流式重建）；需要快照加速/自定义持久化的存储方，注入自己的 ICheckpoint 实现（带真 Writer，快照导出/恢复）。

★ Writer/Reader：段表导出/恢复的公开协议。

★ HasSnapshot()：是否有预存快照可加速恢复（false → 回退扫盘）。

★ 自定义切面：直接实现本接口（不需要碰 internal 的 Coordinator）。
