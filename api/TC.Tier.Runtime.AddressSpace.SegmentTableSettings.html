Parameters

GrowthLimit long

段增长上限（字节，>0；默认 Alignment32M = 32MB，启动后不变）。

MinSegId int

段表最小有效段号（恢复路径首段 segId，默认 0）。

IndexCapacity int

_segIndex 初始容量（= maxSegId + 1，恢复路径用扫盘最大段号；默认 8）。

SpinMilliseconds long

自旋等待时间（毫秒，默认 30*1000 = 30秒）。

WarnEvery int

警告间隔（每多少次尝试记录一次警告，默认 32）。

EnableSingleSegment bool

单段模式（默认 false=多段）。true=仅 seg0，分配超容量直接抛 容量不足（不 spin、不建 seg1）——旧单段语义收口到此。
