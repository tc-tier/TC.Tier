Class TierKvBuilder<TKey, TValue>

Namespace
TC.Tier.Products.Kv

TC.Tier.Products.dll

TierKv 装配器（TierWalBuilder 同构：注入面开放 + StartAsync 一步到位）。

★ 装配两层（D7 同构）：显式层 = 本 Builder（Ring/索引工厂 + formatter/comparer/resolver 注入， 显式胜出）；缺省层 = [KvStore] 生成的封闭形态（formatter 零代码 + 内嵌派生 Ring/索引实现 自动装配）——两条路共用 TierKvAssembly 的 Options→Settings 翻译面。

★ 用法：

var kv = await new TierKvBuilder<long, long>(fs, options)
    .WithRingFactory((fso, o) => new RingOfLong(TierKvAssembly.RingSettings(fso, o), fso))
    .WithIndexFactory((fso, o, ring) => new HashOfLong(fso, TierKvAssembly.HashSettings(fso, o), ring))
    .StartAsync();
public sealed class TierKvBuilder<TKey, TValue> : IDisposable, IAsyncDisposable where TKey : unmanaged, IEquatable<TKey>
