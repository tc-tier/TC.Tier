Class UnifiedXxHash

Namespace
TC.Tier.Core.Primitives

TC.Tier.Core.dll

统一 XxHash 计算工具——仓库内哈希的对外出口（与 UnifiedCrc 同族的校验/哈希原语）。

★ 实现自研化收编自 dotnet/runtime System.IO.Hashing（MIT）：算法/字节序/性能与官方逐位一致， 替换 System.IO.Hashing 调用点不改动任何结果（XxHash64 与 XxHash128 均为公开确定性规范）。

★ 用途：KeyComparer 默认哈希（HashIndex tag/桶位）、QueueKeyComparer、对象存储替身 ETag 等。 64 位为内存内哈希；128 位输出 16B Big Endian 字节（与官方 XxHash128.Hash 同序）。

★ 当前仅一次性形态（无流式消费者）；XxHash64 短 key 热路径零分配。
