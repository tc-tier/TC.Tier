Tier 管理面（二期-D1 NETGAP-005——healthz/readyz 语义 + 最小 admin 协议·产品面）： 挂载请求回调域（0x70——注册区产品自管号），远程可查询节点状态导出与健康探针。

★ 客户端形态：静态 QueryStateAsync(IProtocolTransport, NodeId, CancellationToken) / QueryHealthAsync(IProtocolTransport, NodeId, CancellationToken) （编码请求 → 请求回调 → 解码应答）；服务端形态：构造时传状态供给回调即挂载。
