    Class PagedMirror

    PagedMirror——per-page 多链 checkpoint 镜像（统一帧格式，PerKey 链）。

    ★ 子类实现面（COORDINATION §4 铁律 10）：codec（PMVH/PMFT、CRC32C）+ 页门面 （WritePage/ReadPage——每页一个帧，走基类帧三拍）+ per-page 字典钩子。 机制（帧写入/走链恢复/嵌入 meta/N=2/2PC）全部在 MirrorBase。

    ★ v2 帧化：页 record 从定长整块（头存长度+padding）改为同族帧（双魔术值推导长度、 padding 退役、帧长任意字节边界）——两种镜像一套格式一套机制。
