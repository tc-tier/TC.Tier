    Struct LogMetaPayload

    LogMeta Payload 区结构化首部（4 LogicalAddress = 64B + LastCommittedSeq 8B + LastPreparedSeq 8B = 80B）——水位数据。

    ★ [BinaryLayout] → 源生成器生成 LogMetaPayloadCodec.Write/Read。

    ★ 地址全部 LogicalAddress（承自 spec 27 第一不变量，大小绝不参与）。

    ★ PreparedTailAddress（2PC Abort 回退点）：Prepare 时刻的 pre-prepare 尾快照—— 本轮事务窗口数据的起点。Abort/恢复裁决据此 TruncateSuffix 回退；Empty = 无待回滚窗口。

    参见 base.md §3 D。
