根空间采集/还原管线（raw-medium-and-conversion-design §5）——四态互转的唯一机构。

★ 只依赖 IFileSystem/IFileHandle 接口平面：对根空间内部住着谁一无所知， 任意介质 ↔ 任意介质（含 TierVolume 载体——virtual 介质的 .tier 文件/块设备载体层，已落地点亮）。

★ 采集契约：枚举（EnumerateEntries(string, string, bool) 递归）→ Stat/FileExtra/区间表 → 清单先行 → 逐区间帧化（稀疏保真：洞不占帧）。静默前置（§5.5）： QuietSource 且源置位 MaintenanceGate 时经维护门闩包夹（WriteOperations 档）。

★ 还原契约：目标根空间必须为空（非空即拒——显式失败优于静默合并，§5.3）；目录（父先）→ 文件（帧落位 → SetLength 定逻辑长度 → FileExtra 回填）→ 逐句柄 Flush（Remote 介质 Flush 即持久化）。

★ Stat 时间戳仅入清单审计（ModifiedTicks），不承诺还原——IFileSystem 无时间戳写入平面（§5.2 诚实表达）。

Transfer(IFileSystem, IFileSystem, ImageOptions?)

介质间转移（dd 快道路由入口——raw-medium-and-conversion-design §6.2）。

★ 路由（能力位驱动，非按介质硬编码）：源与目标均置位 ContiguousCapture 且实现 TC.Tier.Core.IO.Image.IContiguousVolume → **字节直拷快道**：双侧维护租约内整卷原始字节顺序拷贝（真·dd，产物 = 整卷字节镜像）。 其余组合 → 结构化管线（TCA1 流经内存中转）。

★ 快道契约：租约由本方法进出（源 WriteOperations 档、目标 AllOperations 档——写入端完全隔离）； 拷贝后长度对账（短读即 IOFailure）。压缩选项对快道不生效 （字节镜像语义——压缩属结构化产物，§6.3）。
