    ★ 恢复后钩子——OnRecoveryCoreAsync(LogRecoveryHints, CancellationToken) 末尾、MarkReady 前调用。

            <p>子类 override 在此做"依赖恢复结果"的装配（EntryLog 设 CommittedOffset + 启提交循环）。
        默认空——DeltaLog 等无此需求的子类不 override。</p>

    ★ 恢复核心：InitializeForWrites（依赖 SectorSize 的装配，引擎就绪后）→ 三级回退 ① hints（外部主动注入的初始化水位——最高优先级，TailAddress 精确 → FileSize 近似） ② meta（结构自管持久化水位）③ 扫盘。与 Metadata/Mirror/Snapshot 统一（用户裁定）。
