API 参考

TC.Tier 全部公共组件的 API 文档。左侧目录树按命名空间分组，点击任一命名空间查看其下类型（Class / Struct / Interface / Enum / Delegate）的完整成员清单。

命名空间一览

命名空间 所属组件 职责
TC.Tier.Contracts.* Contracts 仓储/事务/结构/布局/元数据/序列化的契约接口
TC.Tier.Core.* Core 异步原语 / 互斥回收 / 优先队列 / 缓存计算 / 专用调度 / 故障注入 / 日志可观测
TC.Tier.Core.IO.* Core.IO TierFs 入口 / 本地 / 内存 / 虚拟 / 远端文件系统
TC.Tier.Core.IO.S3.* Core.IO.S3 S3 网络文件系统适配
TC.Tier.Core.Net.* Core.Net 形态面 / Raft 共识 / P2P / Swarm / 安全
TC.Tier.Runtime.* Runtime 存储引擎 / 数据结构 / 会话 / 元数据 / 段表 / Lease
TC.Tier.Products.* Products TierKv / TierQueue / TierWAL / TierBlob / TierTimeSeries
TC.Tier.Products.Net.* Products.Net TierRaftNode（raft × TierWAL 组装）
TC.Tier.CodeGen.* CodeGen 命令壳生成器（CLI / HTTP 双执行面）+ 标注面
TC.Tier.Analyzers.* Analyzers Tier 分层依赖分析器（TCSG130-139）+ TierFs 规范分析器（TCSG120-122）

使用建议

  • 先看契约再读实现：TC.Tier.Contracts.* 是消费方视角的稳定契约，读它能快速理解设计意图
  • Core 原语文档优先：左侧目录中 TC.Tier.Core.* 下每个类型都有使用指南与反模式表（在文档站对应组件页），API 文档作为成员清单参考
  • CodeGen 标注面：源生成器消费的标注属性集中在 TC.Tier.CodeGen.* 命名空间，自定义扩展从这里入手
