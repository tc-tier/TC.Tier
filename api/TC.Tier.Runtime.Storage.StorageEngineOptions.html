MetaTupleFlushInterval

段元组耐久化泵周期——生命周期元组（建段初始/段满）记脏后由后台泵按此周期批量落盘。

★ InfiniteTimeSpan = 耐久化仅锚定 Dispose 补写； Zero = 逐写同步直写（每生命周期点 fsync——小段高频场景的延迟瓶颈形态）。 默认 200ms 批量。

★ 依据（2026-09-08 磁盘销案）：机械盘每 meta fsync ~15-30ms × 小段压测几何 （4KB 段 × 600 创建+段满 ≈ 1200 次串行 fsync ≈ 数十秒）把建段路径拖过测试预算； 泵化后生命周期操作零 fsync 等待。崩溃窗口 ≤ 周期——恢复设计本可容忍 stale 元组 （fileSize 权威回退）；进程存活期缓存读己写恒成立。
