快照多源同步装配（spec-12 §6.1 消费者——SwarmSync 首消费件）：把快照条目流块化 （SnapshotBlockizer）后走多源并行拉取；与单源流式路径 （SnapshotStreamTransfer）共享同一存储端口（IRaftStore 快照读/导入面）， 产物（目标快照区）逐字节一致——对拍契约见测试。

★ 角色对称（spec-12 §4 对称节点）：每节点既可作为 holder（PublishSnapshotAsync(long, int, CancellationToken) 发布块化内容供拉取）也可作为下载方（InstallSnapshotAsync(SwarmManifest, IReadOnlyList<NodeId>, Action<long, NodeId>?, CancellationToken) 多源拉取重装导入）； holder 列表与 manifest 的交换是装配/握手面（InstallSnapshot RPC 携带——归 T6 引擎接线）， 本件只提供机制（发布 → 取 manifest；收到 manifest + holders → 安装）。

★ 下载侧重装 O(快照字节) 缓冲（无序块按几何偏移落位后顺序解析导入——导入面仍逐条流式消费）； 传输线经 SwarmSync 逐块流式（O(块) 驻留）。
