Interfaces

IAsyncOperation

后台操作句柄（无结果变体）——后台统一执行的返回对象（如 StartReclaim）。

★ 取代旧 IReclaimOperation（与 ICompactOperation 两套同构句柄合一）；实现基座 = Core.Primitives.AsyncOperationBase（状态机 + 事件 + 取消 + 进度，见 sync-async-bridge.md §4）。

★ 消费面 = AsyncOperation 公开消费成员全集：轮询（Status/IsCompleted/ Exception）、异步等（WaitAsync(CancellationToken)）、同步兜底等（Wait(int, CancellationToken)）、 终态取异常（ThrowIfFailed()）、事件订阅（Progress/Failed）、 取消（Cancel()）。

★ 取消：Cancel() 触发后台操作中止（后台尽快回滚/终止，配合 WaitAsync(CancellationToken) 等"回滚完全完成"）； WaitAsync(CancellationToken) 的 ct 仅取消"等待"本身，不取消操作。

★ 事件时序契约：终态事件先于 WaitAsync(CancellationToken) 唤醒——等待者苏醒时事件必已投递； 订阅竞态用 IsCompleted 兜底（先订阅后查，true = 完成早于订阅，事件已错过）。

IAsyncOperation<TResult>

后台操作句柄（有结果变体）——携带结果的后台操作（如 StartCompact 返回 CompactResult）。
