通用并发优先队列——基于细粒度锁 skip-list（Herlihy 2006 lazy 版本）。

★ 任意可比优先级：支持任意 long 优先级值（值小者先出）。

★ 严格优先级 + 同优先级 FIFO：key = (priority, sequence)，sequence 单调递增保证同优先级 FIFO。

★ 细粒度锁：每节点一把 SpinLock，hand-over-hand 加锁，不同区间操作并行。

★ lazy validation：Peek/Find 不加锁（读 marked 字段）；Insert/DeleteMin 加锁后 validate（全层级—— 标记即完整摘除，marked 节点永为瞬态）。

★ 内存回收简单：unlink + 解锁后节点安全可回收（无需 epoch/hazard pointer）。

★ 定位：细分锁实现——任意 long 优先级 + 消费者较少的场景。严格优先级+FIFO 语义使同优先级尾插与 min 头摘是两个串行热点，吞吐上限由热点决定；无锁高吞吐场景用 AsyncPriorityQueue<T> （Route A 生产基线），离散枚举优先级用 BucketPriorityQueue<TPriority, T>。

算法依据：Herlihy, Lev, Luchangco, Shavit. "A Simple Optimistic Skip-List Algorithm" (DISC 2006)。
