Class DiskFileSystem

Namespace
TC.Tier.Core.IO.Disk
Assembly
TC.Tier.Core.dll

磁盘文件系统——TC.Tier.Core.NativeInterop.FileNative 的面向对象封口 + 根空间命名空间平面（层级相对路径，filesystem-root-space-design）。

★ 构造（动词面 §2.3）：New(string, DiskFileSystemOptions?, ILogger?) / Open(string, DiskFileSystemOptions?, ILogger?) / OpenOrCreate(string, DiskFileSystemOptions?, ILogger?)（懒初始化糖——bind-any 终态； 磁盘根目录是部署决策，无全局单例）。

★ 卷锁：lock file + FileShare.None（Win）/ flock（Unix）——跨进程互斥、崩溃自愈 （进程死亡后句柄关闭，后来者可重新获取）。

★ Dispose 契约（磁盘方向）："离开目录"——仅释放 fs 自持资源（卷锁违约释放并告警）； 不关闭消费者持有的句柄；Dispose 后 Open/命名空间操作抛 ObjectDisposedException。

EnterMaintenance(string, MaintenanceScope, CancellationToken)

进入维护态（能力位 MaintenanceGate 门控；未置位实现抛 Unsupported）—— 采集/还原静默快照的通用前置（raw-medium-and-conversion-design §8）。

★ 语义：闭门 → 阻塞等待在途变异归零（ct 可取消；消费者业务在途收敛是消费者契约，§8.2） → 返回 IDisposable 租约（Dispose 即解除）。非重入：维护中二次 Enter 抛 FileIOException(UnderMaintenance)。

★ scope=WriteOperations：命名空间变更与句柄写族拒绝（读放行——备份档）； scope=AllOperations：读写全拒（完全隔离档）。 被拒操作抛 FileIOException(UnderMaintenance)——与能力位语义 Unsupported 分离，调用方可映射"维护中"提示。

★ Flush/FlushRoot 不拒（关闭协议的组成：进维护 → 收敛 → Flush 置 clean）。
