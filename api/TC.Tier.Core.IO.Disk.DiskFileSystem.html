Class DiskFileSystem

Namespace
TC.Tier.Core.IO.Disk
Assembly
TC.Tier.Core.dll

磁盘文件系统——TC.Tier.Core.NativeInterop.FileNative 的面向对象封口 + 根空间命名空间平面（层级相对路径，filesystem-root-space-design）。

★ 构造（动词面 §2.3）：New(string, DiskFileSystemOptions?, ILogger?) / Open(string, DiskFileSystemOptions?, ILogger?) / OpenOrCreate(string, DiskFileSystemOptions?, ILogger?)（懒初始化糖——bind-any 终态； 磁盘根目录是部署决策，无全局单例）。

★ 卷锁：lock file + FileShare.None（Win）/ flock（Unix）——跨进程互斥、崩溃自愈 （进程死亡后句柄关闭，后来者可重新获取）。

★ Dispose 契约（磁盘方向）："离开目录"——仅释放 fs 自持资源（卷锁违约释放并告警）； 不关闭消费者持有的句柄；Dispose 后 Open/命名空间操作抛 ObjectDisposedException。
