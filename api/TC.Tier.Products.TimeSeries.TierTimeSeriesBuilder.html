Class TierTimeSeriesBuilder

Namespace
TC.Tier.Products.TimeSeries
Assembly
TC.Tier.Products.dll

TierTimeSeries 构建者（tc-tier-timeseries-spec §3——四段式装配惯例同 TierQueueBuilder： Options 配置链 → Builder → StartAsync 一步到位）。

★ 组合设计思想（注入优先、回落默认）：零件规格全在 TimeSeriesOptions； 可替换件全走 With\* 注入——Ring 工厂、Ring meta 策略工厂、水位 meta 工厂、索引工厂、 索引比较器、共享 epoch（多结构同域惯例）、引擎选项变换器、logger；不注入 = 内部默认实现。

★ 启动状态机同 TierQueueBuilder：只能成功启动一次（重复抛）；失败可重试（销毁重建， 对齐 RecoveryBase "Failed 销毁重建" 哲学）。
