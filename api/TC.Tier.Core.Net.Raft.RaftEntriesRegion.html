AppendEntries 条目区（线格式 v3——信封之死后的单拷贝直写区）。

★ 区布局（全部小端）：[Count 4B][×N: RaftAppendEntryHeader 13B + Content]。 嵌入 EntriesRegion blob 随生成 codec 上线（blob 外壳 [Len 4B][bytes] 归 WireMessageGenerator 管辖）；区内布局在本文件单点声明。

★ 写面 = WriteEntriesToAsync(long, int, IBufferWriter<byte>, long[], CancellationToken)（存储直写帧缓冲——单拷贝： 存储页 → 帧，消灭 ReadEntriesAsync 逐条枚举 + Tuple + 逐条 EncodeInto 拷贝）； 读面 = TryReadCount(ReadOnlyMemory<byte>, out int, out int)/TryReadEntry(ReadOnlyMemory<byte>, ref int, out long, out byte, out ReadOnlyMemory<byte>) 游标式零拷贝切片。
