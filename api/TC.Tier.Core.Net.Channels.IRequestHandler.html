请求回调接收面（spec-12 §5.2——形态面对高层的 API 契约）：单请求 → 关联应答 → 超时。

★ 回调契约同数据报 IDatagramHandler：快进快出（重活自排队）、 异常不外泄不致命；不回复 = 对端超时（ReplyAsync 零次调用合法）。

★ 幂等约定：at-least-once（RetryPolicy）下同 CorrId 请求可能重发——传输端 去重窗口缓存重放应答不重复执行；跨重启窗口清空（§8.4）——handler 幂等是使用方约定。
