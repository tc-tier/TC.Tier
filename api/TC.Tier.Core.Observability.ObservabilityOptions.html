    Class ObservabilityOptions

    可观测性配置聚合 —— 追踪 + 指标两信号各自独立配置（对齐 OTel TracerProvider + MeterProvider）。

    ★ 注入引擎/结构，由工厂分发到各子视图。

    ★ 日志不由 Options 控制——日志的级别/过滤由注入的 ILoggerFactory 实现自行决定。

    ★ 默认零开销：new ObservabilityOptions() → 追踪关、指标关。
