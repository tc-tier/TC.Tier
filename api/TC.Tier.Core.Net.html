NetIOException

Core/Net 唯一的网络 IO 异常类型（Core.IO.FileIOException 同构先例——家族·网络层标准）： 传输面失败（目标未连/握手失败/连接失败/会话 Reset/流拒绝）的统一出口——InProcess/TCP 两介质同构，Socket 层错误不裸抛（IOException 是 BCL 底层类型，网络层契约 面一等类型）。

★ 铁律：不携带任何协议语义（raft/p2p 词汇）——协议语义由机制面在边界包装补充。

★ 派生自 IOException（BCL）——消费者可用单一 catch (IOException) 兜底； 底层原生错误（SocketException 等）以 InnerException 携带保留诊断。

RuntimeTunables

运行时可变旋钮（二期-D6 NETGAP-011——重连/保活/超时的运行时可变面）： 装配期 TransportOptions 不可变面不受影响——本类型只承载"允许运行期调小/调大 而不破坏装配"的旋钮子集，由 UpdateRuntimeTunables(Action<RuntimeTunables>) 校验后生效。

★ 各旋钮独立生效（无跨旋钮一致性承诺）；读取方在用点取当前值（拨号每轮/请求每次/保活每拍）。

NodeId

节点身份——网络核心协议一等结构（spec-12 §2：自定义结构，不借任何 BCL 类型当协议身份）。

★ 组合 Opaque16（16B 不透明字节串——布局唯一真源在彼处，本类型是身份 语义包装）：字节原序直拷、无端序解释，协议字节与运行时类型解耦。

★ [BinaryLayout] 标注 = 线协议标准嵌套件（spec-12 §10）——生成的 NodeIdCodec 委托 Opaque16Codec（小端直写承载字 = 字节原序直拷）；本类型内零 BinaryPrimitives、 零偏移字面量。

★ 布局零语义：不塞集群号/代次/预留位——集群归属是握手字段，fencing/代次是 raft 任期 与证书的事；预留字段 = 想当然。

★ 宽度 128-bit：集群身份第一性质 = 免协调不碰撞，128-bit 使其永不成议题 （身份每消息一次、从不每条目，字典基数 = 节点数）。

★ Guid 只在边界：配置/数据库/第三方互操作的适配转换；线上与存储无 Guid 概念。

★ 安全绑定文本 = ToString() 文本形式（mTLS 档 SAN nid:<hex32> URI 条目；KeyPair 档 NodeId↔公钥钉扎绑定——spec-12 §3.4）。

Opaque16

16B 不透明定长字节串（通用线协议容器——spec-12 §2 "声明即字节原序直拷"的通用形态； 语义化包装如 NodeId 组合本类型，16B 布局唯一真源在此）。

★ [BinaryLayout] 标注（嵌套件——spec-12 §10）：生成的 Opaque16Codec 小端直写 双承载字 = 字节原序直拷；ctor/CopyTo(Span<byte>) 走生成的单字段读写——本类型内零 BinaryPrimitives、零偏移字面量。

★ 布局零语义：纯字节容器（IPv6 地址/密钥指纹/校验和等）；字节字典序全序与 hex32 文本形式是容器的自然属性，不赋予任何领域语义。

Opaque4

4B 不透明定长字节串（通用线协议容器——IPv4 地址等；与 Opaque16 同型的窄形态）。

★ [BinaryLayout] 标注（嵌套件）：生成的 Opaque4Codec 小端直写承载字 = 字节原序直拷； ctor/CopyTo(Span<byte>) 走生成的单字段读写——本类型内零 BinaryPrimitives、零偏移字面量。
