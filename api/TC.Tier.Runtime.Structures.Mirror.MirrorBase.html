    头截断（N=2 立即回收最老 checkpoint 方向）。ConfirmCommitted 自动调；也可业务显式调。

    保留窗口：当前 + 上一个；TC.Tier.Runtime.Structures.Mirror.MirrorBase.ComputeRetainFloor() 返回保留窗口最老版本地址 （PagedMirror = 所有页 keepAddr 最小值——引擎 MinAddress 是全局水位，只能推进到所有页都同意回收的地址）。
