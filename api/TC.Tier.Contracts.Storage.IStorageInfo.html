    Interface IStorageInfo

    存储信息视图——只承载"描述存储引擎能力与配置"的只读属性 + 路径解析方法，不承担任何 IO 操作。

    ★ 定位原则：本接口是 IStorageEngine 的纯信息子集—— "引擎是什么样、配置如何、段在哪"（声明性/配置性信息）。 IStorageEngine 在此基础上追加"对设备执行 IO"的行为（Append/Read/Write/Flush 等） 以及这些行为产出的动态水位（AllocatedTail/CommittedTail 等）。

    ★ 介质/绝对路径/容量不在其列：介质 = 注入引擎的根空间文件系统（Runtime 层 IFileSystem）， 引擎只持相对路径（EngineName 即根空间下子目录）；容量归 fs 卷自身。 零实现纪律：本层不引用 Core——DIO 探测结果（Core IO 四态枚举）由 Runtime 引擎类型自身属性 StorageEngine.UnbufferedSupport 暴露，不进契约面。

    SegmentFileName(int)

    解析指定段号的段文件路径（★ 根空间下相对路径，'/' 唯一分隔符）。

    ★ 多段模式 = {engine}/{engine}.{segId}；单段模式 = {engine}/{engine}（忽略 segId）。 引擎名可多级（"a/b"）。

    ★ 子系统（Compact/Checkpoint）必须用此方法定位段文件，禁止自己拼路径—— 单段/多段差异由实现保证，避免子系统各自猜测导致路径错位。
