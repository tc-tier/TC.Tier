    Interface ITransactionLog

    事务协调者——跨数据结构原子提交的全局提交点。底层提供接口 + 默认实现（TransactionLog）。

    设计见 transaction-design.md。

    ★ 职责边界：底层提供原子提交原语 + 默认实现，上层编排 2PC（哪些结构参与、顺序、回滚）。

    CommitAsync(CancellationToken)

    ★ 真正两阶段提交（本次改造）：Phase 1 foreach Prepare → 任一失败 → foreach Abort； 全部成功 → persist commit record（原子点）→ Phase 2 foreach ConfirmCommitted。

    落盘分层：参与者 Prepare 各自 flush 数据+meta；协调者只持久化 commit record（原子点）。

    返回新 seq。Phase 1 失败抛异常（已 Prepare 的全部 Abort）。

    LoadAndReconcile()

    ★ 恢复协调（本次改造为双向分支）：Load commit record + 对每个参与者裁决。

    - committedSeq == 0（空盘/损坏）：所有有悬干数据的参与者 Abort

    - LastCommittedSeq < committedSeq → ConfirmCommitted(committedSeq)（正向：未同步推进）

    - LastPreparedSeq > committedSeq → Abort(LastPreparedSeq)（反向：超前悬干丢弃）

    调用方须在调用本方法前 Register 所有参与者（按依赖顺序：底层先，上层后）。
