FakeTimeProvider

假时钟（故障注入面补全设计 件一——时钟缝测试替身，零外部依赖；不用 Microsoft.Extensions.TimeProvider.Testing 包）。

★ 双钟模型：单调钟（GetTimestamp()——快进推进、停走/倒流免疫、墙钟跳变不污染） + 墙钟（GetUtcNow()——跳变/漂移可注入，建模真实 NTP 校时与走速偏差）。

★ 单调戳 ms 域（TimestampFrequency = 1000，与 Environment.TickCount64 同域）—— 落点 deadline 算术零变更。

★ 快进：Advance(TimeSpan) 同步推进双钟并触发到期定时器（回调在 Advance 调用线程按到期序 同步执行——零真实睡等、确定性重现）；Advance(TimeSpan.Zero) = 冲刷已到期定时器。

★ 定时器：CreateTimer(TimerCallback, object?, TimeSpan, TimeSpan) 返回的 ITimer 由假钟驱动——周期定时器在单次 大跨度 Advance 内按周期连发（对齐真实周期语义）。定时器回调抛出的异常原样冒泡到 Advance 调用方 （测试可见性优先，不静默吞）。
