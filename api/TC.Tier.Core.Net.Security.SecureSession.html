KeyPair 档会话密钥（握手产物——spec-12 §3.4）。

★ 前向保密形态（Noise IK 同构）：静态密钥只做签名（身份证明），密钥协商用 每连接临时 ECDH——静态私钥日后泄露不危及历史会话。

★ 双向密钥（ Initiator/Responder 方向分离——同键双向自反攻击防御）+ 确认密钥 （Final 帧密钥确认 MAC）。粒度在帧保护层消费（FrameProtection—— AEAD=加密+认证；MAC-only=仅认证）。
