WholeMirror——整体单链 checkpoint 镜像（统一帧格式，Single 链）。

★ 子类实现面（COORDINATION §4 铁律 10）：codec（WMHD/WMFT、CRC64）+ 会话门面 （三拍直通基类帧原语）+ 单链钩子（链头推进/保留窗口）。机制（帧写入/走链/尾锚/嵌入 meta/ N=2/2PC）全部在 MirrorBase。

★ 写会话真流式：BeginSession → AppendChunk × N → EndSession——不知尺寸、零缓冲、 CRC64 边写边累积收官落尾（全程不需要知道总长）。

★ 生命周期：new + Initialize()（后台恢复）+ WaitForReady()。详见 src/TC.Tier.Core/docs/lifecycle.md。
