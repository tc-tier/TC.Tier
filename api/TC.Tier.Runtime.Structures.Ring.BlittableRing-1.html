    Class BlittableRing<TKey>

    BlittableRing — Ring 实现类。

    ★ 继承 RingBase，override record 字节几何插槽（override 全 sealed——JIT 去虚化保持）。

    ★ 所有 K/V 读写方法在 RingBase 中实现，仅特定 override + Codec 留在此处。

    ★ 公开且可继承（去类级 sealed）——生成器 [RingKey] 封闭薄类（RingOfLong 等）的派生基座 （设计稿 §2：开放泛型内核手写一次，封闭形态生成器产出，消费面只见封闭类型）。
