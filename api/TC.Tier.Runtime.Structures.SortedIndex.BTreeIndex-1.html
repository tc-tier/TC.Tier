BTreeIndex 主存储格式布局 partial——机制归基类（TC.Tier.Runtime.Structures.SortedIndex.SortedIndexBase`1.TryDump 编排/ 版本链/后台循环/帧走链），本件只实现格式：32B 几何 + 物化。

★ 帧体布局：[几何 32B]——rootAddr(16) entryCount(8) structSize(4) pad(4)。 节点本就写时持久化在自持引擎（节点变更即 WriteNodeContent，引擎副本恒完整）—— 帧不写节点流，物化=设根 + 引擎读回根节点，零结构调整（无分裂/无重放重建）。

★ 正确性（对齐 HashIndex 同构）：dump 表覆盖 [?, W] 完整折叠；> W 混入条目靠重放 (W, End] 幂等收敛（帧内 root 恒为 dump 时刻最新根——fuzzy 无逐槽拷贝，几何原子三字段）。
