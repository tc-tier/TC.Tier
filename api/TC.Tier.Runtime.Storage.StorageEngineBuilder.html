存储引擎构建者（builder.build——设计决策：Options 构建配置 → Builder 构建引擎 → Start 启动引擎一步到位）。

★ 外部使用者的唯一引擎入口：using var builder = options.Builder(fs); var dev = builder.Start(hints) 或 StartAsync(hints)——构建 + Initialize + 就绪等待一体；实现类（StorageEngine）internal 不对外，不允许外部直接调 Initialize（启动统一经本类的 Start/StartAsync）。

★ 启动状态机：Start/StartAsync 只能成功启动一次（重复启动抛 InvalidOperationException）；失败可重试——启动失败销毁重建引擎实例 （对齐 RecoveryBase"Failed 销毁重建"哲学），再次 Start 用新引擎。

★ 装配依赖（compact/checkpoint/logger/hub/epoch）在 Options.Builder(...) 传入—— 构建上下文与配置（Options）分离。
