集群配置（spec-04 §1 定案）——节点有序列表；版本 = 承载它的日志 index；meta 槽不存配置 （恢复 = 重放日志/快照帧流至配置条目——配置与状态机同构，日志即状态机）。

★ 稳定序列化（Serialize()——配置条目 payload 格式）：配置变更经日志复制 跨节点传播、重启经快照/重放恢复——格式必须稳定。

AddLearners(IEnumerable<(NodeId Id, string EndPoint)>)

批量加 learner（#507c——一条配置条目携多节点，机群批量引导 O(1) 轮协议）。

★ 安全性：learner 不投票不计多数派——批量加入不改变投票成员集，新旧配置的多数派 完全重合，single-server 变更的 quorum 交集论证平凡成立（论文 §4.2 一次一节点的动机在投票成员 变更，learner 批量不在其约束域）。已存在的成员跳过（幂等）；全跳过 = 原样返回（零提案）。

★ 上限 200：配置条目 wire 格式 Count 字段 1B（≤255）——留余量；更大的引导批次分多条 批量条目（万级拓扑的配置面扩容见 #507a/b 立项的格式 v3）。

public ClusterConfig AddLearners(IEnumerable<(NodeId Id, string EndPoint)> learners)
