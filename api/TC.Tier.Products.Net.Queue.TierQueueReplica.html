TierQueueReplica——TierQueue 的集群模式（tierqueue-replicated-spec：一队列实例 = 一 raft 组）。

★ 分工：状态变更（Enqueue/Ack/组生命周期/到期记账/辖权/回收）经共识全序复制 （apply 确定性 ⇒ 全组同地址，消息 ID = LogicalAddress）；消费面经组辖权租约仲裁 （HomeCmd 经共识、GroupEpoch fencing——接管即 +1，旧辖权迟交确定性拒绝）；Dequeue 纯本地读零共识。

★ 提案路由：本端为 raft leader 直提；否则 NotLeaderException 携 leader 经转发路由送达 leader （客户端零感知——"任意节点可写"读面）；非辖权 Dequeue/Ack 抛 NotGroupHomeException （异常驱动重定向——客户端策略缺省）。

★ 恢复语义：副本队列引擎为易失物化（raft 日志 = 持久真相）——冷启动经业务快照导入 （ring 检查点帧 + 组 meta 镜像）+ 增量重放续接；Enqueue 未 applied = 不可见（提交前不可见—— 比本地 FireAndForget 更强）；pending 纯内存 = at-least-once 重放窗继承。
