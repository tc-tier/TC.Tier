security-aware DNS stub resolver（#498——RFC 1035/2782/6891 客户端面全契约，零外部依赖叶子位）： 查询（SRV/A/AAAA）＋解析＋TTL 缓存＋EDNS0/安全位。

★ 传输：UDP:53 首选；TC 置位 → TCP 重试；超时 + Retries 次（指数退避）；多 server 轮询容错（每次尝试轮换下一个——ServFail/超时跟随）。

★ 名展开（K8s CoreDNS 形态）：绝对名（尾点）直查；相对名按 ndots 阈值——点数 ≥ 阈值 先绝对后 search，否则先 search 后绝对（resolv.conf / Windows 网卡配置自举）。

★ CNAME 跟随：深度上限 8，聚合 MinTtl（链上各跳取最小）；SRV 不跟随（RFC 2782：SRV 属主 不得为别名）。记录集保持应答节顺序——同应答字节 → 同结果。

★ Non-goal（#498 永久排除）：DNSSEC 签名验证链与递归迭代解析（stub 以 AD 位消费递归层 验证结论——DnsSecurityStatus）；DNS server 面；mDNS/LLMNR/DNS-SD 组播族。
