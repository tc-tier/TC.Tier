    Interface IStorageEngine

    存储引擎接口——提供顺序追加、随机覆写、跨段读取、刷盘、截断、回收、碎片整理等功能。

    ★ 继承 IStorageInfo（纯信息视图：定位/配置/路径解析）+ ILifecycle<THints>（生命周期观测：IsReady/RecoveryState/WaitForReady*）。 本接口在其上追加 IO 行为（Append/Read/Write 等）+ 动态水位（AllocatedTail 等）。 子系统（Meta/Compact）只需依赖 IStorageInfo 即可，避免与 IO 耦合。

    ★ 初始化：不在接口面——启动统一经 StorageEngineBuilder.Start/StartAsync 一步到位 （内部 Initialize + WaitForReady），不允许外部直接调 Initialize（设计决策：接口面消除）。 恢复 hints（EngineRecoveryHints，只含恢复水位——段表双尾修正）经 Start(hints) 传入； 段生长上限/分段开关是构造期配置（Options 配置链传入），不经启动入口。

    CalculationAddress(LogicalAddress, long)

    计算给定地址前进指定长度后的新地址。

    ★ 纯计算（无空间管理），支持 ±：length ≥ 0 前进（跨段进位正确）；length < 0 回退 （跨段借位正确，越过 MinAddress 返回 Invalid）。

    ★ 仅前进/仅回退的方向原语在段表层（AdvanceAddress/RetreatAddress 分立）； 引擎层 CalculationAddress 是统一的双向计算动词——名字叫"计算"，就得加减都算。

    这个不是真实的地址分配，仅用于逻辑推算——应搭配 Allocate(long) 分配空间地址后， 业务层（如 Log 的页缓冲模型）在已预留的地址区间内推算 entry 地址。典型场景：Log 先 Allocate(long)(PageSize) 拿到页起始地址 pageStart，entry 写进内存页时地址 = CalculationAddress(pageStart, entryOffsetInPage)，页满 Write(LogicalAddress, ReadOnlySpan<byte>) 覆写预留区。 这样 entry 地址在写页时即已知，不依赖页提交（解决"先写内存页后 Append 得地址"的顺序死结）。

    实现：正值委托 LogicalAddressRegistry.AdvanceAddress、负值委托 RetreatAddress（跨段进位/借位均正确）。

    GetDistance(LogicalAddress, LogicalAddress)

    ★ 计算两个地址之间的字节距离（from → to，跨段自动累加）。

    返回 to - from 的字节数。若 from > to 返回负值。

    ★ 这是纯逻辑推算（不分配、不 IO）——委托 LogicalAddressRegistry.GetDistance（跨段进位正确）。

    上层（Structures 层）需要知道两个地址之间的字节数时（如区间大小、空间统计），必须调用此方法， 禁止手动对 Offset 做减法（段内偏移跨段无意义）。

    ★ from/to 必须 ≤ AllocatedTail（已分配地址空间内）。超出范围抛异常。

    StartRangeCompact(LogicalAddress, LogicalAddress, IReadOnlyList<(LogicalAddress Start, long Length)>)

    启动区间 Compact（申报活区间版——记录粒度精确搬迁）——搬迁规划按使用方申报的活记录区间执行， 而非物理 allocated 枚举（簇粒度）。

    ★ A8/§XVIII：Reclaim 打洞是记录粒度，物理 allocated 是簇粒度（NTFS 簇内有 存活邻居的洞整簇保配，fsutil 实证）——小记录场景物理规划对洞不可见 → 全量拷贝零回收。 区间表同样无记录粒度洞位（VII-3：洞 OR 并入大记录 sparse 位）——记录粒度真相只在使用方。 本重载让使用方申报活记录 [Start, Start+Length)，引擎按申报精确搬迁。

    ★ 契约（严苛，A8 信任模型）：申报区间必须 ⊆ [from, to)（越界抛）；未申报的已分配 区间视为洞，不搬迁——漏报活数据 = 该数据整理后不可达。范围外（from 前、to 后）仍按 物理 allocated 保守保留。MigrationMap 覆盖全部申报记录的 Start。
