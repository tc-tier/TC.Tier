16B 不透明定长字节串（通用线协议容器——spec-12 §2 "声明即字节原序直拷"的通用形态； 语义化包装如 NodeId 组合本类型，16B 布局唯一真源在此）。

★ [BinaryLayout] 标注（嵌套件——spec-12 §10）：生成的 Opaque16Codec 小端直写 双承载字 = 字节原序直拷；ctor/CopyTo(Span<byte>) 走生成的单字段读写——本类型内零 BinaryPrimitives、零偏移字面量。

★ 布局零语义：纯字节容器（IPv6 地址/密钥指纹/校验和等）；字节字典序全序与 hex32 文本形式是容器的自然属性，不赋予任何领域语义。
