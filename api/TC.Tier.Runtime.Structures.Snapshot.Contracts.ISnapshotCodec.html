    Interface ISnapshotCodec

    SnapshotBase 数据格式 codec 接口（对齐 IMirrorCodec/IMetadataCodec 模式）。

    流式帧：[Header 14B 规范][Payload][Footer 28B（Magic+TotalLength+EntryCount+Crc64）]。 FooterMagic 供 Backward 扫描定位帧尾（恢复取真尾）；CRC64 流式增量累积（data 可能跨多次追加）。
