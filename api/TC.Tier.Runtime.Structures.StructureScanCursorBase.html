游标骨架基类——提供 Direction 存储 + MoveNextAsync 的同步委托默认实现。

各结构游标类继承本类，只 override MoveNext + 扩展 Current*/结构专属成员。 有真异步 I/O 的结构 override MoveNextAsync；否则用默认同步委托。
