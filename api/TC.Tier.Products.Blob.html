Classes

BlobReadSession

流式读会话——OpenRead 直通结构层帧读取器（CRC64 逐帧校验，双 buffer 预读，冷热透明）。

★ 校验时机：读至对象末尾自动补读对齐补零触发帧尾解析——CRC64 校验失败抛 IOException。

BlobWriteSession

流式写会话——OpenWrite 直通结构层帧写入器（CRC64 增量流式累积，GB/TB 写路径内存 = 双缓冲页恒定）。

★ Complete/Abort 显形（spec 裁定②）：CompleteAsync(CancellationToken) 收口登记（返回句柄）； Dispose 未 Complete = Abort（尾截断回滚——结构层 append 可回滚语义），与 KV 会话 Dispose 收口惯例对齐。

★ 单会话契约：同一会话禁止并发写（结构层写尾单写者）；不同对象经产品写闸串行。

TierBlob

TierBlob——本地 Blob 空间（tierblob-spec：SnapshotBase 的产品封面，零新结构）。

★ 组合配方（spec §1 六大裁定）：StreamSnapshot 单形态数据引擎（{name}.blob.data——对象 = 一段连续地址区间的 CRC64 帧流，句柄 = 起始 LogicalAddress）+ 对象表（{name}.blob.meta—— 版本链记录帧流，meta 真相源）。

★ 帧几何不变式：每帧扇区对齐（数据区补零）——物理布局 = 逻辑布局，重启后恒等映射读回成立； 定长读免帧解析（数据区物理连续直达）。

★ 线程模型：读并发无锁（表镜像点查 + 引擎读）；写单通道（产品写闸串行——结构层写尾单会话 契约，多生产者并行 = Runtime 迭代候选，spec §4 诚实降级）。

★ 恢复（spec §5）：数据引擎 join（Backward 找帧尾 O(1)——无 meta，帧自描述）+ 表重放 （meta O(1) 水位 + 定步长）→ 对账（Active 逐个验帧 → 损坏标墓碑；孤儿帧不可见空间保留）。

TierBlobBuilder

TierBlob 构建者（四段式装配惯例同 TierTimeSeriesBuilder：Options 配置链 → Builder → StartAsync 一步到位）。

★ 组合设计思想（注入优先、回落默认）：零件规格全在 TierBlobOptions； 可替换件全走 With* 注入——数据/表引擎工厂、引擎选项变换器、logger；不注入 = 内部默认实现。

★ 启动状态机同 TierQueueBuilder：只能成功启动一次（重复抛）；失败可重试（销毁重建）。

TierBlobOptions

★ record——测试/组合根可用 defaults with { … } 派生（对齐 TimeSeriesOptions 先例）。

ITierBlob

TierBlob——SnapshotBase 的产品封面：无索引语义的 GB/TB 级大对象流式存取（tierblob-spec）。

★ 对象句柄 = 起始 LogicalAddress（写完即得；同址即同对象——raft 形态下确定性 apply 全组同址， 泛化复制继承）。凭句柄直达数据，零元数据查询；GetInfoAsync 才查表。

★ 语义边界（spec 裁定②③）：顺序写整对象/顺序读——随机 seek 覆写不进产品语义（KV 的事）； 覆盖写 = 先 Delete 再 Put（新句柄）。

★ 持久化（分配-持久分离）：Complete 返回句柄 = 内存可见（含对象表登记已持久——表 Prepare/Confirm 收口）；数据面落盘显式 FlushAsync(CancellationToken)（引擎 fsync 屏障）。

★ 删除 = 墓碑 + 空间保留（裁定⑥）：物理回收走 ReclaimDeletedAsync 手动档（B1）。
