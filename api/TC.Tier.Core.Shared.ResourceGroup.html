    Class ResourceGroup

    资源组——引擎/设备资源的生命周期管理器（组合持有，非继承）。

    • 按名注册/查询去掉旧 this[int] 下标索引（隐式契约脆弱）；用 Add<TResource>(TResource, string?, ResourceOwnership) / Get<T>(string) 显式按名。
    • 后期添加支持构造期 params + 运行期 Add<TResource>(TResource, string?, ResourceOwnership)（解决旧版一次性传死、meta engine 等后期资源只能靠各基类自建 _disposables 列表的分裂）。
    • 所有权二态ResourceOwnership 区分 Owned（我释放）/ Referenced（外部管，只跟踪）。注入引擎等用 Referenced——泄漏可见但不被 Dispose。
    • object 单存储资源可能是 IDisposable、IAsyncDisposable 或两者都实现（如 IStorageEngine）。 ★ IAsyncDisposable 不继承 IDisposable，只异步的资源（如 IReadSession）也收；不实现两者其一的资源在 Add 时直接抛。
    • 聚合异常Dispose 逐个释放、收集异常，全部尝试完后聚合抛 AggregateException（不因单个失败跳过其余，也不静默吞）。

            <p>⚠️ <b>子类构造器警告</b>：构造期未加锁依赖"对象尚未暴露"——若子类在构造器里启动线程/回调

          把 this 传给并发组件（对齐 .NET 构造器安全准则）。</p>

    Add<TResource>(TResource, string?, ResourceOwnership)

    添加资源（重名抛 ArgumentException）。

            <p>★ 泛型入口：<code class="typeparamref">TResource</code> 约束为 class（编译期类型安全）。
          运行期校验至少实现 <xref href="System.IDisposable" data-throw-if-not-resolved="false"></xref> 或 <xref href="System.IAsyncDisposable" data-throw-if-not-resolved="false"></xref>（泛型约束无法表达"或"关系）。</p>
        <p>★ <xref href="System.IAsyncDisposable" data-throw-if-not-resolved="false"></xref> 不继承 <xref href="System.IDisposable" data-throw-if-not-resolved="false"></xref>：只异步的资源（如 <code>IReadSession</code>）也收。</p>
        <p>★ <code class="paramref">ownership</code>：默认 <xref href="TC.Tier.Core.Shared.ResourceOwnership.Owned" data-throw-if-not-resolved="false"></xref>（Dispose 释放）；注入资源用 <xref href="TC.Tier.Core.Shared.ResourceOwnership.Referenced" data-throw-if-not-resolved="false"></xref>（只跟踪诊断，Dispose 跳过）。</p>
        <p>★ 线程安全：用 <code>lock</code> 保护，可被后台恢复 task 与主线程并发调用。</p>

    Remarks

    逆序释放（后加的先释放）；仅 Owned 资源释放，Referenced 跳过。 同步路径优先 IDisposable（防同步上下文死锁）。聚合异常展平。

            <p>★ 只实现 <xref href="System.IAsyncDisposable" data-throw-if-not-resolved="false"></xref> 的资源在同步 Dispose 里阻塞等异步完成（语义与异步入口一致）。</p>
