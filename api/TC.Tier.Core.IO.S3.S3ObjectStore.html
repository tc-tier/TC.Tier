S3 兼容对象存储——IObjectStore 默认实现（SigV4 自写、零外部依赖）。

★ 一个实现覆盖全部 S3 兼容云（S3 / OSS(S3 兼容端点) / MinIO / R2 / B2——换 endpoint/credentials 即达）； COS 不承诺（V5 签名差异大，独立实现另议——设计 §7.5）。

★ 寻址：path-style（{endpoint}/{bucket}/{key}）——MinIO/自建端点标准形态。 canonical URI 与请求 URL 同编码器生成（S3 特例：不归一化不二次编码）。

★ 重试矩阵（§9.9）：幂等操作（GET/HEAD/PUT/DELETE/List/UploadPart）对 5xx/429/网络抖动指数退避重试； CreateMultipartUpload 不重试（可能双开会话）；Complete 重放安全（NoSuchUpload → NotFound，桥层回读校验）。

★ 线程安全：HttpClient 并发共用（连接池复用）；multipart 会话独立无共享态。
