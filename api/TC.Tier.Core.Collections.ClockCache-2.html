    Class ClockCache<TKey, TValue>

    ★ CLOCK 近似 LRU 缓存——高性能、零分配热路径、线程安全（Interlocked CAS，无全局锁）。

    ★ 算法：环形数组 + 访问位 + 开放寻址法哈希（线性探测）。Redis/PostgreSQL/Windows 内存管理都用 CLOCK。

    ★ 命中率 90-95%（近似 LRU，工程足够）；淘汰 O(1) amortized（时钟扫描）。

    ★ 对齐 OverflowPool/PinnedBufferPool 的"底层组件+性能指标"范式。

    可复用：Ring 冷页缓存（ClockCache<long, AlignedMemoryManager>）、任意 key→value LRU 场景。

    参见 src/TC.Tier.Core/docs/cache-and-compute.md。
