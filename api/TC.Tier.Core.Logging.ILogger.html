    Interface ILogger

    Kernel 日志接口 — 替代 Microsoft.Extensions.Logging.ILogger。

    内核代码通过此接口记录日志，默认 NullLogger 零开销。

    ★ 简化签名：去掉 M.E.Logging 的泛型 TState + formatter——内核只做文本日志， 结构化参数由 LoggerExtensions 的扩展方法用 string.Format 先格式化再传入。
