KvSession<TKey, TValue>

KvSession——TierKv 会话（tierkv-design.md §3.1/§3.2，W2 会话全集）：写集可见性 + 原子批（F2 多 key 全或无）+ pending 簿记（CompletePendingAsync 刷盘收口）+ EPVS 版本保护（Serializable）。

★ 单线程对象（FASTER 同契约）：一个会话实例只归一个逻辑线程使用，内部零锁； 并发正确性由「每会话一实例」表达。

★ 档位语义（KvSessionConditions）：None=读恒走索引；ReadMyWrites（缺省 D3）= 写立即应用+写集读己之写；Serializable=RMW 全集+同步临界区 EPVS pin。

★ EPVS pin 粒度 = 同步临界区（async-first 判例）：Serializable 的同步写在版本保护下执行—— 版本过渡不可能跨越进行中的临界区；操作之间过渡可完成。设计稿 §3.1「ctor Enter/Dispose Leave」的 生命周期 pin 与 LightEpoch 线程亲和（每线程 Resume/Suspend 必须同线程配对）+ 异步续体线程跳转 不可兼得——落定 per-op 保护形态（FASTER ClientSession 同为 per-op 保护）；版本化快照读 W5 深化。

★ pending 模型：写恒登记高水位地址（FireAndForget/WaitForPending 不即时刷）； CompletePendingAsync(CancellationToken) 把 [FlushedUntil, 高水位] 一次刷盘收口（组提交形态—— Committed 档即时刷为逐写 FlushUntil，组提交策略 W6 接管）。

★ 原子批（F2）：Begin 后写走暂存（stage 可见性隔离——本会话读可见、他人与索引不可见）； CommitAsync = Ring 追加 → 2PC Prepare（落盘悬空）→ ConfirmCommitted（提交点）→ 索引换绑 （可见性）——崩溃任一窗口全或无（悬空 Prepare 恢复即弃 + 派生重放教义）。

TierKvBuilder<TKey, TValue>

TierKv 装配器（TierWalBuilder 同构：注入面开放 + StartAsync 一步到位）。

★ 装配两层（D7 同构）：显式层 = 本 Builder（Ring/索引工厂 + formatter/comparer/resolver 注入， 显式胜出）；缺省层 = [KvStore] 生成的封闭形态（formatter 零代码 + 内嵌派生 Ring/索引实现 自动装配）——两条路共用 TierKvAssembly 的 Options→Settings 翻译面。

★ 用法：

    .WithRingFactory((fso, o) => new RingOfLong(TierKvAssembly.RingSettings(fso, o), fso))

    .StartAsync();

TierKv<TKey, TValue>

TierKv<TKey,TValue>——本地持久 KV 存储（tierkv-design.md：单一泛型产品类，TierWal 同构）。

★ 组合配方：Ring（数据唯一真源——append-only 结构化记录+变长本体+自动溢出）+ 主索引（缺省 HashIndex 点查 O(1)；BTree/SkipList 经 KvIndexKind 装配）。 索引是可重建派生结构（派生重放教义）——任何索引切换/重建都不丢数据。

★ 写语义：append-only 换绑——Put 恒为「Ring 追加新记录 → 索引 CAS 换绑地址」， 旧值留 Ring 由回收（W6）治理；Delete = 墓碑写入 + 索引清槽（恢复重放跳过已删 key）。

★ 装配闸门：开放泛型不落消费面（同 BlittableRing 律）——ctor 收 protected internal、 类不封闭，供 [KvStore] 生成的封闭形态派生（formatter 零代码）；显式路径 = TierKvBuilder<TKey, TValue>（工厂注入显式装配）；测试经 IVT 直构。

IKvFunctions<TKey, TInput, TValue, TOutput, TContext>

KV Functions 完整模型（tierkv-design.md §1——FASTER IFunctions 五参形态完整落地：用户裁定）。

★ RMW 三流（§3.3 统一为「读折叠 → Format → 追加 → 索引 CAS 换绑」）： Initial（key 无值造值）/ Copy（不可变记录折叠——旧记录保留，版本历史是我们的多出能力）/ InPlace（语义位——append-only 无可变区，实现为「本记录追加前最后折叠」：引擎先征询本钩子， false 回落 Copy 流——对齐 FASTER mutable→immutable 派生序）。

★ 返回 false 契约：Initial/Copy 返回 false = 折叠失败 → RMW 以 Error 收口（零写入）；InPlaceUpdater 返回 false = 本槽位放弃 → 回落 Copy 流（FASTER 同款派生）。

★ 写侧钩子为语义位校验面（返回 false = 拒绝该写入——FASTER 原型为 void/bool 混合， 本契约统一 bool 值语义）；读侧钩子负责 value→output 翻译。

ITierKv<TKey>

TierKv 消费面契约（tierkv-design.md §0——单一泛型产品类，TierWal 同构）。

★ 面分层：本接口 = 字节层（存储真面）；类型化值面（TValue 直存直取）由 [KvStore] 生成的封闭类经装配的 IValueFormatter<TValue> 承载（D7：生成器自动 + builder 显式覆盖）。

★ 波次扩展：W2 会话全集 / W4 IKvFunctions 完整模型 / W5 检查点快速恢复 / W7 范围扫描按波次扩展本接口。

IValueFormatter<TValue>

值格式化契约（tierkv-design.md——TValue 无约束 + 注入格式化接口；formatter = 纯转 byte）。

★ 结构层存储恒为字节（Ring 结构化记录 + 变长本体 + 自动溢出，append-only）—— formatter 是 TValue 与字节序列的唯一翻译层；byte/byte[]/ROM<byte>/unmanaged 内建零实现 （[KvStore] 生成器自动发射，D6/D7 裁定），其余 TValue 由用户实现或 builder 显式注入。

★ 契约：GetSize(TValue) 与 Format(TValue, Span<byte>) 对同一 value 必须一致 （GetSize(v) == Format 写入字节数）；Parse(ReadOnlySpan<byte>) 是 Format 的严格逆（逐字节可逆）。
