Swarm manifest Merkle 树哈希（spec-12 §6.1 增量——复制家族设计件 C 反熵对账的比对依据）： 块 CRC32C 为叶子，每 SubtreeFanout 块聚一个子树根，子树根聚全局根。

★ 纯函数（manifest Checksums 的派生计算——零状态）；全局根相等 = 整体一致零传输； 不等 = 沿子树粒度定位差异区间（叶子层区间批量比对，O(块数/扇出) 请求、4B/块比对流量）。
