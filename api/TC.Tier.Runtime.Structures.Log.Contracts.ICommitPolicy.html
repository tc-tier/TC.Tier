    Interface ICommitPolicy

    提交策略接口——EntryLog group 提交引擎按策略判定"何时"触发提交（不决定"怎么"提交）。

    ★ 策略只决定"何时"，提交执行链（FlushUntilAsync + MetaPolicy.Commit + 推进 CommittedOffset）由 EntryLog 内部闭环。 参见 EntryLog.md §3.5。

    内置策略：

    - TC.Tier.Runtime.Structures.Log.GroupCommitPolicy：三维度阈值兜底（数据量/时间/记录数任一满足）

    - Synchronous：恒 true（每次 Append 立即提交，单条强制）

    - External：恒 false（不自动提交，靠手动 CommitAsync 或 2PC）
