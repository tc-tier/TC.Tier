    Class AsyncOperation<TResult>

    一次性后台操作的状态句柄（有结果变体，仿 Task{T}）——后台操作携带结果（如 CompactResult）。

    ★ 用法：new AsyncOperation{TResult}(name, logger, externalCancel) → worker 完成时 ReportSucceeded(result)；消费方 await op.WaitAsync() 拿结果（失败/取消重抛）。

    ★ Completed 事件（携带结果）先于 WaitAsync(CancellationToken) 唤醒（时序契约见基类）。
