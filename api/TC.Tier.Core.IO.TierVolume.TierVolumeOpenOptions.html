虚拟文件系统打开选项（medium-protocol-and-parity-design §6——继承 FileSystemOptions 基类）。

★ 原布尔 ReadOnly 并入基类 Access（G2 三态化—— Read = 只读打开[dirty 降级形态]，ReadWrite = 缺省；Write = 纯摄入——虚拟卷无此概念，Open 即拒）。

★ 基类 QuotaBytes = 挂载收紧：有效上限 = min(quota, 供给)（§5.3）； Label = Open 校验（不符即抛 fail-fast）。
