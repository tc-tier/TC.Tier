    ParseSize(string)

    将字符串表示的大小解析为字节数。

    支持后缀：k/K/KB（千字节）、m/M/MB（兆字节）、g/G/GB（吉字节）、t/T/TB（太字节）、p/P/PB（拍字节）。

    示例："4k"→4096，"8MB"→8388608，"12g"→12884901888。
