异步优先队列——基于 lock-free 跳表（Fomitchev–Ruppert marker 删除协议）。

★ 高并发入队/出队 O(log n) 平均复杂度；出队时队列为空则异步等待或取消。

★ Route A 正确性基线（根因档案决策）：回归论文前提世界—— 边存直接对象引用 + marker 节点表达逻辑删除（单引用 64 位 CAS，无 128 位打包）、 节点 fresh 分配交 GC 回收（不池化、不 epoch、不 Id 寻址）。论文不变式 I1~I5 由构造消除， 不再自证回收协议。性能代价：每次入队一次 Gen0 分配（LOH 无压力）。详见 SkipListPriorityQueue<T>（锁基变体）与 docs/async-priority-queue-root-cause.md。

marker 协议要点：victim 的 Forward[L] 被 CAS 成 AsyncPriorityQueue<T>.Marker （marker.Next 持真实后继）即"已逻辑删除"；物理摘除 = 前驱边 CAS 绕过 victim 直连 marker.Next。marker 永不被改写，victim 摘除后整体交给 GC——并发读者永不会读到回收后的节点。

★ 并发语义：多生产者安全；多消费者不丢不重，但并发出队时"最小元素"判定是 竞争性的（各出队以各自 mark CAS 为线性化点），严格最小序需要单消费者（或 SkipListPriorityQueue<T> 的持锁 DeleteMin）。

★ DEBUG 构建内置链校验器（key 严格递增 + 成环护栏），每 64 次操作自动巡检， 测试可显式调 TC.Tier.Core.Collections.AsyncPriorityQueue`1.ValidateInvariants 定点取证。
