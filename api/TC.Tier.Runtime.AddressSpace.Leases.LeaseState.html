操作 lease 状态——CAS 守护。终态（Committed/RolledBack/Finalized）语义等价：Finalize 已收敛、Extents 已释放；Dispose 守卫只判 != Active。

public enum LeaseState

Fields

Active = 0

Lease 处于活跃状态，尚未提交或回滚。

Committed = 1

Lease 已提交（全员 chunk 走提交路径——最后增量者触发）。

Finalized = 3

混合方向终态——部分 chunk 提交、部分回滚，回滚者补满 doneMask 时自动收敛。

RolledBack = 2

Lease 已回滚（整体 Rollback 触发）。
