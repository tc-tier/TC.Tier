EntropyProbeReq

反熵对账消息（spec-12 §6.1 增量——复制家族设计件 C：副本漂移检出）。

EntropyProbeReq  [Tag][ManifestId 16B][Level 1B][RangeStart 4B][RangeCount 4B]
EntropyProbeResp [Tag][Count 4B][Hashes ×N 4B]

★ 只读比对协议：请求某层某区间的哈希集（Level 0 = 全局根 1 个；Level 1 = 叶子区间 每块 CRC32C）——对账消息不触发任何写路径。RangeCount ≤ 64（一个子树）。

SourceAnnounceMsg

持有者上报（spec-12 §6.1 增量——多源快照分发完整化）：follower/重启节点 → 当前 leader 的 单边声明"我持有此基线"——leader 端 manifest 代际持有表登记（重复上报幂等）。

★ 错报无害：内容寻址 + 块级 CRC32C 校验（拉取侧防线）——错报只损失带宽分担不产生错误数据。 ★ 上报 = 尽力送达（丢失由下次上报/换届重报覆盖）；应答 = 传输闭环空应答（非语义确认）。

SwarmAntiEntropy

Swarm 反熵对账（spec-12 §6.1 增量——复制家族设计件 C：把"分发"升级为"持续收敛"）。

★ 单轮形态（RunOnceAsync(ISwarmBlockSource, NodeId, SwarmManifest, CancellationToken)）：全局根比对（相等 = 整体一致零块传输）→ 不等 = 叶子层区间批量比对定位差异块 → 经 DownloadBlocksAsync(SwarmManifest, IReadOnlyList<NodeId>, IEnumerable<long>, Action<long, NodeId>?, CancellationToken) 定向 只拉差异块（校验和+换源全复用）→ 写回本地可变源（TryWriteBlock(Opaque16, long, ReadOnlyMemory<byte>)）。 只读比对协议（EntropyProbe）零写路径；修复块过 VerifyBlock(long, ReadOnlySpan<byte>) 防线。

★ 触发归装配面：周期（AntiEntropyInterval，缺省关闭）× 对端轮转（Majority 档 = leader 周期发起；LeaderLocal/Swarm-only 档 = 各节点对 known peers 轮转——HyParView 提供成员表）。反熵不救已丢的写（LeaderLocal 未复制尾部——异步复制物理边界）， 只收敛已分发内容的漂移。

SwarmDownloadException

Swarm 下载失败（spec-12 §6.1——单块全源耗尽 = 整体失败；装配点幂等：重下载一致）。

SwarmManifest

块清单（spec-12 §6.1——内容寻址基线数据的描述：块号/偏移/长度/校验和）。

★ 权威源 = raft committed 内容或通告水位——manifest 由权威方构建供给（装配点幂等： 同一内容同一 Id 重下载结果一致）；块定位纯几何推导（偏移 = 块号 × 块大小，末块截短）。

★ 校验和 = 每块 CRC32C（UnifiedCrc——错块拦截的依据）； 块大小由构建方定（运行参数零写死——上限受 MaxBlockBytes 线协议防御界约束）。

SwarmManifestId

Swarm manifest 内容标识派生（#436 件四——语义化入口）。

★ 不可变对象假设下 manifest 是内容的稳定函数：raft 域 = 快照覆盖点 index 承载； 内容域 = 16B 字节原序直拷（如 Blob ObjectId 的 16B 布局原序）。

SwarmManifestReq

清单发现请求（#436 件三——按内容标识拉清单，任何 holder 可应答；空应答 = 未持有）。

SwarmManifestResp

清单发现应答（HasManifest=false = 未持有——拉取方换下一种子/退化直连源）。

★ 清单字段拍平在线形态（线编解码成员支持集无嵌套 record——HasManifest 门控有效性）。

SwarmMerkle

Swarm manifest Merkle 树哈希（spec-12 §6.1 增量——复制家族设计件 C 反熵对账的比对依据）： 块 CRC32C 为叶子，每 SubtreeFanout 块聚一个子树根，子树根聚全局根。

★ 纯函数（manifest Checksums 的派生计算——零状态）；全局根相等 = 整体一致零传输； 不等 = 沿子树粒度定位差异区间（叶子层区间批量比对，O(块数/扇出) 请求、4B/块比对流量）。

SwarmMessage

SwarmSync 消息族（spec-12 §6.1 × §6 形态映射——取块 = 请求回调： 单请求 → 关联应答 → 超时；CorrId 由传输承载，消息族不携带）。

★ 线格式（生成物：[Tag 1B][字段声明序]，Opaque16 原序嵌套件/小端/Data 变长 blob）：

GetBlockReq        [Tag][ManifestId 16B][BlockIndex 8B]
GetBlockResp       [Tag][ManifestId 16B][BlockIndex 8B][HasBlock 1B][Len 4B][Data]
SourceAnnounceMsg  [Tag][ManifestId 16B]

★ 未持块应答 = HasBlock=false（Len 0 无 Data——holder 侧块缺失是正常形态非错误； 下载方据此换源）。

SwarmMessageCodec

SwarmMessage 消息族线编码——[WireMessage] 派生。

SwarmOptions

SwarmSync 参数（spec-12 §6.1/§4.5——运行参数零写死，文中数值仅为缺省）。

SwarmSync

多源并行同步（spec-12 §6.1——BitTorrent 同构：块清单 manifest + 并行度 K 多源拉取 + 块级换源重试 + 块校验和防错源）。

★ 形态映射（§6）：取块 = 请求回调（at-most-once 缺省——块级换源重试是投递语义的 换源变体）；持有者 = 显式列表（gossip 捎带集成随 T5 快照安装消费时定义）。

★ 挂载（§3.5）：StartAsync 经 TC.Tier.Core.Net.Channels.ICoreProtocolPort 内部口注册 SwarmSync（0x03）请求 handler；本地块源经 SetSource(ISwarmBlockSource?) 装配（holder 侧内容知识归使用方）。

★ 边界（§6.1）：raft 日志复制不多源（线性一致）——本机制仅内容寻址的基线数据； 装配点幂等 = 同一内容同一 Id 重下载结果一致（manifest 校验和保证）。

★ 下载语义：逐块流式产出（O(并行度 × 块) 驻留——消费者逐块落盘，GB 级不驻内存）； 单块全源耗尽 = 整体失败（SwarmDownloadException——部分装配失败重来， 装配点幂等）；错块拦截（校验失败 = 换源 + 计数 + Net 视图 CrcFailure 钩子）。
