    Invalid

    无效地址哨兵（段号 -1、扩展字段 -1、偏移 -1）——表示"无值/未初始化/越界"。

    ★ 与 Empty (0,0) 区分：Empty 是合法的 seg0 起点，Invalid 才是"没有值"。

    ★ 校验用 IsValid：SegId >= 0 && Offset >= 0（Invalid 的 SegId=-1 或 Offset=-1 不满足）。

    IsValid

    地址是否有效——SegId >= 0 && Offset >= 0（Invalid 哨兵的 SegId=-1 返回 false，Empty 的 SegId=0 返回 true）。

    ★ 用于区分"合法地址（含 seg0 起点 Empty）"与"无效/未初始化/越界（Invalid）"。
