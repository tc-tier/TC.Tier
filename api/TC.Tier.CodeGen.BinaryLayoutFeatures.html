[BinaryLayout] 生成能力组合标志。

默认 None：仅生成 Write/Read/Validate。 按需组合 StructSize、FieldConstants、FieldReaders、FieldWriters。

[Flags]
public enum BinaryLayoutFeatures

Fields

All = Constants | FieldAccessors

全部能力。

Constants = StructSize | FieldConstants

StructSize + FieldConstants = 全部常量。

FieldAccessors = FieldReaders | FieldWriters

Read_* + Write_* = 全部单字段读写方法。

FieldConstants = 2

生成每个字段的 Offset_* / Size_* 偏移/尺寸常量。

FieldReaders = 4

生成每个字段的 Read_* 单值读取方法。

FieldWriters = 8

生成每个字段的 Write_* 单值写入方法（对称 Read_*，收口字节序，避免业务层手写 BinaryPrimitives）。

None = 0

默认：仅生成 Write/Read/Validate。

StructSize = 1

生成 StructSize 常量（= [StructLayout].Size 值）。
