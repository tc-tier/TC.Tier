索引结构主存储帧格式——两族索引（探测/比较）共用的三段式帧格式 （设计稿 V2/index-persistence-evolution-design.md）。

★ 自校验三段式（段表同款理由——写入的是外部存储就不完全相信，只认自己的写入格式）：

  • 头（先行校验，快速失败）：magic/version/flags/kind + 体长——不符立即判无效，不读体；
  • 体（自定界）：结构内容由族自己的几何块推出边界（Hash=桶区/溢出池；BTree/SkipList=32B 几何，节点在引擎内）；
  • 尾（总验收）：footerMagic + 水位 W + CRC64（覆盖头+体+尾前缀）——有效性最终裁决。

★ 帧格式知识归 codec（IProbingIndexCodec 实现——子类=格式定义者）， 本类型只承载结构定义与共享常量；源生成器（[BinaryLayout]）生成 ProbingIndexHeaderCodec/ProbingIndexFooterCodec。
