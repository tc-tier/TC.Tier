TierKv<TKey,TValue>——本地持久 KV 存储（tierkv-design.md：单一泛型产品类，TierWal 同构）。

★ 组合配方：Ring（数据唯一真源——append-only 结构化记录+变长本体+自动溢出）+ 主索引（缺省 HashIndex 点查 O(1)；BTree/SkipList 经 KvIndexKind 装配）。 索引是可重建派生结构（派生重放教义）——任何索引切换/重建都不丢数据。

★ 写语义：append-only 换绑——Put 恒为「Ring 追加新记录 → 索引 CAS 换绑地址」， 旧值留 Ring 由回收（W6）治理；Delete = 墓碑写入 + 索引清槽（恢复重放跳过已删 key）。

★ 装配闸门：开放泛型不落消费面（同 BlittableRing 律）——ctor 收 protected internal、 类不封闭，供 [KvStore] 生成的封闭形态派生（formatter 零代码）；显式路径 = TierKvBuilder<TKey, TValue>（工厂注入显式装配）；测试经 IVT 直构。

CompareAndSwapAsync(TKey, LogicalAddress, ReadOnlyMemory<byte>, KvCommitPolicy, TimeSpan?, CancellationToken)

地址版 CAS（乐观锁——「地址即版本」的直接体现）：当前绑定地址 == expectedAddress 才追加 value 并换绑；否则返回 false + 当前绑定（零写入零事件）。

★ 语义锚点：expectedAddress = Invalid 表示 「当前不存在」（防并发插入——与值版 expectedValue=null 同位）；绑定记录已过期（惰性判）视为不存在 （返回 false + CurrentAddress=Invalid）。

★ 原子性（文档明示）：换绑点 CAS×CAS 经 TC.Tier.Products.Kv.TierKv`2._casGate 串行——并发 CAS 恰一成功； CAS 与普通 Put/Delete 竞争仍是 last-writer-wins 换绑（CAS 不是全局写锁，防丢失保证仅对 其他 CAS 调用方成立——etcd txn 同语义）；raft 形态命令经 apply 单 worker 串行——天然全局原子。 成功 = Put 事件（写路径既有发布）。

★ TTL（获取即租约形态——锁配方语义源）：timeToLive 非 null 时产物带过期， 「比较 + 写入 + 挂过期」单一原子单元——expiryTicks 在 TC.Tier.Products.Kv.TierKv`2._casGate 临界区内、比较通过后 计算（锁获取 = expectedAddress=Invalid 的 NX + 租约；fencing token = NewAddress，地址即版本）。 null = 无过期（与无 TTL 形态逐字节同）。

ReclaimAsync(CancellationToken)

日志回收（§3.5——版本链未开启的「低频全表扫」钦定路径）：扫 Ring [Begin, Tail) 逐记录判定 index.Find(key) == 本记录地址（存活=某 key 当前最新记录）→ 存活最小地址为安全下界 ——其下记录必被同 key 更新记录/墓碑取代 → TruncatePrefix(LogicalAddress, bool) 逻辑回收。

★ 读安全：下界 ≤ 一切存活记录地址，截断只回收严格低于下界的前缀（下界处记录存活）； 并发读经索引命中的地址恒 ≥ 下界。

★ 索引帧互溶：帧条目指向旧存活记录，若已落回收区则必被同 key 更新记录取代—— 恢复重放 (W, Tail] 重绑定最新地址（帧加速语义不受回收影响）。

★ 会话钳制项（§3.5 min(活跃会话最早可见地址)）：本模型会话写集持值副本不持地址、 读恒走索引最新——会话不钉历史地址，钳制项空缺（Serializable 快照读深化时补位）。

★ 物理段保留（truncateDevice=false 逻辑截断）——读安全优先，物理回收策略后置。 提交门内串行（与检查点/原子批互斥）；未落盘尾不回收（clamp 至 FlushedUntil）。
