    Class AsyncOperationBase

    一次性后台操作状态句柄的机制基座——AsyncOperation / AsyncOperation<TResult> 共用（docs/sync-async-bridge.md §4）。

    ★ 通用后台操作原语（升级）：取代 Storage 层 IReclaimOperation/ICompactOperation 两套同构句柄的手写实现（TCS + 事件 + 时序对齐三层各写一遍）——事件/取消/进度/结果/等待 一套契约一处实现，后台操作统一 new AsyncOperation(...) + Report*。

    ★ 实现 IAsyncOperation（Contracts）——消费面全集见接口（含 AsyncOperationStatus 状态轮询 / IAsyncOperation.Wait(int, CancellationToken) 同步兜底 / ThrowIfFailed() 终态取异常）。

    ★ 三种消费模式：① 轮询 Status/IsCompleted（多消费者安全）； ② WaitAsync(CancellationToken)（异步一等公民，失败/取消重抛）； ③ Wait(int, CancellationToken) （同步兜底——内嵌 AsyncManualResetEvent 的 「自旋 → park 分片」分层等待，全程有界，绝不裸 Task.Wait()）。

    ★ 事件：Progress（进度）+ Failed（失败/取消终态，含订阅者异常隔离）； 成功终态事件由子类经 OnSucceeded() 触发（无结果变体无 Completed 事件——await 等价）。

    ★ 取消：Cancel() 触发内部链接令牌（构造可链接外部取消——引擎 Dispose 自动取消在途操作）； CancellationToken 供后台 worker 在检查点响应。

    ★ 状态机：构造即 Running（可见性原则）；终态经 CAS 单次转移、 不可逆；首个 Report 生效，后续幂等 no-op（对齐 RecoveryBase"Failed 销毁重建"哲学——重试 = 新建操作）。

    ★ 事件时序契约（Storage 历史 flaky 根因区收口）：终态事件先于完成信号置位——等待者 （WaitAsync(CancellationToken) 唤醒）苏醒时事件必已投递；订阅竞态经 IsCompleted 兜底。

    ★ 泄漏绊线：终态 Failed/Canceled 且从未被任何消费模式观察 → 终结器告警（无 logger 静默， 对齐 LifecycleBase 泄漏探测哲学）。

    ★ #if DEBUG：状态转移环形记录（最近 16 次：时间戳/线程/方向）， Describe() 自动携带——对齐 SpinRWLock 值示波器。

    Wait(int, CancellationToken)

    ★ 同步兜底等待——分层策略（自旋 → park 分片，内嵌 AsyncManualResetEvent.Wait(int, CancellationToken) ）， 全程有界，绝不裸 Task.Wait()。

    ★ 语义：完成（含失败）→ true / 重抛失败异常；超时 → false；ct 取消 → OCE。 调用方拿到 false 即取得超时现场责任（桥的 Run 便捷入口据此 WARN + 抛 TimeoutException）。

    ⚠️ timeoutMs 必须 > 0（同步等待必须有界——docs/sync-async-bridge.md §8.1）。
