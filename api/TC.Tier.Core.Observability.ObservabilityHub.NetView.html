Class ObservabilityHub.NetView

Namespace
TC.Tier.Core.Observability

TC.Tier.Core.dll

Net 传输维度视图（spec-12 §9.1 第五轮裁定：在 Hub 加视图，不是自己造——第六维度， 对齐 Storage/Log/Index/SegmentAllocator 形态）。peer 一律以 hex32 文本标签过界 （Core 不依赖 Core.Net——兄弟层不互依）。

★ 语义：帧量 采样（确定性百分比——热路径零开销）； 错误/丢弃全采（reconnect/CRC/握手失败/UDP 发送失败/保活断连/丢弃计数）； per-protocol = tag（维度即 tag 零字段爆炸）。Core.Net 只调本视图，绝不直调 sink。
