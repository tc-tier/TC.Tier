业务状态机接口（spec-05 §1 定案）——日志即状态机：业务状态 = 已提交日志前缀的确定性函数；重建 = 重放。

★ 业务方唯一必须实现 ApplyAsync(long, ReadOnlyMemory<byte>, CancellationToken)（按序应用已提交命令——index 单调递增、与日志序一致； 只被 ApplyPipeline 单 worker 调用——业务存储无并发写，结构层积木直接可用）。

★ at-least-once 契约：apply 可能重复（断电重放 appliedIndex 之后区间）——实现须幂等/容忍重复 （raft 标准语义；at-most-once 会话去重归用户面 spec-08）。

★ ExportStateAsync(IAsyncTransferWriter, CancellationToken)/ImportStateAsync(IAsyncTransferReader, CancellationToken) = 可选优化路径（业务状态导出/导入， 冷启动免全量重放——存储与传输由使用方自理，协议层零绑定）；不使用不阻塞任何正确性。
