    Class OverflowPool<T>

    固定大小溢出对象池。并发安全（基于 ConcurrentQueue<T>）。

    ★ 指标：hits/misses/overflows 计数 + GetStats()（对齐 PinnedBufferPool 覆盖度）。

    容量上限为软约束（Soft cap）：高并发 TryAdd 下可能瞬时超出 size 几个， 因 ConcurrentQueue 的 Count 快照与 Enqueue 非原子。这对当前调用方（disposer 为 no-op， 超出项被丢弃）无正确性影响；如需硬上限须改用自旋锁或 CAS 容量跟踪。
