    Class RollbackException

    ★ 协调回合回滚异常——Session 管理层回执"本回合已按协议回滚"的规范形态 （复制决策 false/超时/异常 → Abort 已 Prepare 者 → 本异常回执；见 session-manager-design.md §6）。

    语义：结构侧悬干已截断（D2 边界回退），调用方可安全重试（staged 缓冲已清空——重试须重新 Stage）。
