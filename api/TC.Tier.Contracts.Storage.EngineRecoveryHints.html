    Struct EngineRecoveryHints

    引擎恢复提示——恢复期对段表双尾水位的修正值（扫描/上层知识）。

    ★ 只携带水位：生命周期参数（段生长上限/分段开关）构造期传入引擎，不经此类型 （构造 = 配置，启动 = 双尾）。

    ★ 两值可空：null = 该尾不修正（维持持久化 footer / 构造默认）。引擎恢复流程负责 翻译为段表的 SetStartupTails(StartupParameters)。
