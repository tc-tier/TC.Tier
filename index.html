分层存储

本地 / 内存 / 虚拟 / 网络 / S3 多介质平权，TierFs 统一句柄与镜像。

Raft 共识

Core.Net 三形态（Client/Server/P2P）+ Swarm Transfer，TierWAL × Raft 引擎。

.NET 8 原生

专用线程调度 + AsyncPump 泵域 + 受控 TaskSink，零 fire-and-forget 纪律。

可组合产品

TierKv / TierQueue / TierWAL / TierBlob / TierTimeSeries，单机到分布式平滑切换。

声明驱动纪律

TCSG120-139 分析器强制分层依赖与禁用模式，零警告红线。

可观测 + 性能基线

结构层 / 引擎层 / 产品层全链路 perf 基线，BDN 基准 + 云上长稳验证。
